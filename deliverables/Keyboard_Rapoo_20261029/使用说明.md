# RAPOO 104 键键盘 · 3ds Max 2026 可编辑工程

本模型根据用户提供的键盘正面照片，在 **3ds Max 2026.2** 中原生构建、保存和渲染。未使用 Blender。用于视觉展示与后续建模修改。

## 打开和修改

1. 在 **3ds Max 2026 - Simplified Chinese** 中选择「文件 → 打开」，打开 `Keyboard_Rapoo_3dsMax2026.max`。原生 MAX 文件直接打开，无需导入。
2. 按 `H` 按名称选择对象；`Cap_` 开头是 104 个独立键帽，可在「修改」面板编辑多边形。
3. `Legend_` 和 `Function_Icon_` 开头的对象为原生 **Text + Extrude（文字＋挤出）**。在修改堆栈中选择底部 Text 修改文字、字体和大小。双行字符为两个独立文字对象。
4. `KEY_` 开头为按键装配辅助对象；移动一个装配对象，可以连同键帽、文字和支柱一起调整。`KEYBOARD_RAPOO_ROOT` 管理整体。
5. 图层 `01_Case` 外壳、`02_Switch_Seats` 底座、`03_Keycaps` 键帽、`04_Legends` 字符、`05_Underside` 底部、`06_Key_Assemblies` 按键装配、`07_Cameras` 相机、`08_Studio_Lights` 灯光。
6. 原生材质为标准材质，无外部贴图依赖；使用 Windows 常见字体 Arial 和 Segoe UI Symbol。修改颜色时编辑材质即可。

## 交付文件

- `Keyboard_Rapoo_3dsMax2026.max`：优先使用的原生可编辑工程。
- `Keyboard_Rapoo.fbx`：通用导入文件。几何、字符和材质保留，文字已转为网格；要改文字请用 MAX。
- `Keyboard_Rapoo.glb`：从同一 Max 场景实际求值网格导出的网页预览，可旋转、缩放和查看线框。
- `Keyboard_Hero.png` / `Keyboard_Top.png`：Max 真实渲染的透视图和正面图。
- `verification.txt`：保存后重新打开 MAX、检查可编辑结构、干净场景导入 FBX 的检查结果。
- `web-export.json` / `SHA256SUMS.txt`：网页模型统计与文件完整性校验。

## 比例与还原范围

参考只有正面照片，没有实物尺寸、侧面和背面。模型约 **388 × 123.8 × 19.2 mm**，系统单位为厘米；尺寸为按图片比例设定，可整体缩放。104 键布局、导航列、方向键、单宽数字 0、上方空白面板按照片重建。字标和部分功能图标以可编辑字符近似；键帽曲面与材质为视觉重建。底部检修板、脚垫和螺丝为示意结构，不代表原厂内部或背部设计，不用于制造。

网页 GLB 使用基础颜色与粗糙度近似 Max 材质；原生修改、灯光和渲染请以 MAX 文件为准。本次已提供预先导出的预览文件，不代表网站已具备自动转换任意 MAX 工程的云服务。
