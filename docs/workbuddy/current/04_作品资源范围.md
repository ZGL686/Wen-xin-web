# 作品与数据范围

## 开箱可运行的五件内置作品

`源码/data/works.json` 包含灯、沙发、柜子、卡通莓糖小屋和键盘。它们的 MAX 在 `源码/public/originals/`，GLB、封面和详情图片在 `源码/public/portfolio/`，随源码一起完整复制。房子是 2026-11-05 用户确认替换的卡通新版。四件基线作品的原件和 GLB 哈希见 `verification.json`；键盘同样纳入整包 SHA-256。

## 三件补充作品

`补充作品资源/` 按原项目路径保留以下本地文件，便于在新站个人空间导入：

- 鼠标：`assets/3d source/ARC01_Mouse_3dsMax2026.max`。对应真实预览在 `源码/data/models/arc01-mouse.glb`，为原站受保护衍生模型，不能移入 public。
- 茶壶：`assets/3d source/Porcelain_Teapot_2026/3d.max` 与同目录 `peony_albedo.png`，`assets/pipeline/Teapot.glb`、两张实际渲染和 `docs/models/teapot/`。移动场景后若 Max 提示贴图丢失，将贴图重新关联到同目录 PNG。
- 显示器：`assets/3d source/Monitor_27_3dsMax2026.max`、`assets/pipeline/Monitor_27.glb`、两张实际渲染和 `docs/models/monitor/`。

这些是可复用的作品文件，不是数据库恢复包。茶壶此前为私密作品；不要自动把附带原件或私密节点公开。新站导入会产生新作品/版本，不能声称保留了旧历史。如需保留旧 ID、真实历史、作者和分享链接，应走下面的数据迁移。

## 远端数据尚未导出

用户后来上传的作品、每版文字、权限、公开指针、作者资料和会话记录仍在原站 R2。本包没有访问/导出这些记录，也没有导出浏览器 Cookie。不得从内置五件或附带八件模型推断远端作品总数和私密数据数量。

完整迁移需要按服务端当前合同导出 `sessions/`、`profiles/`、`records/`、`versions/`、`files/`，并包含兼容旧数据所需的索引和前缀；具体以 `worker/api.ts` 为准。记录清单、对象数量、字节和哈希，在私有目标存储导入后验证权限和回滚。公开源码包不能混入这些数据。

旧域名的 Host Cookie 无法自动跨域。需要为实际作者设计有验证、有时限的迁移授权交接；不要分配给新站第一个访客，不新增用户未要求的账号登录。当前浏览器收藏保存在旧站 origin 的 localStorage，需要另行迁移偏好，复制服务端作品不会带走收藏。

`工程资料/wiki_memory/` 是脱敏工程记录快照，包含历史事实；以当前状态、当前源码和本包新增说明判断最新状态。历史「文心/形间/账号登录/旧四作」说明不应覆盖当前长序方案。
