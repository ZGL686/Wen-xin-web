# 补充作品资源

补充作品资源/ 提供本地已有的 ARC01 鼠标 MAX、青花茶壶 MAX/贴图/GLB/渲染和显示器 MAX/GLB/渲染，以及茶壶/显示器建模验收文档。它们不属于 data/works.json 的五件系统展品，不要擅自改为公开系统作品。

这些本地文件有助于迁移后恢复真实预览和原件，但不包含原 R2 作品记录、版本、作者归属、公开设置或会话。请先迁移并核对原 R2 数据，再按原作品 ID、版本和权限关联；不能凭本地文件推断原站数据或用新作品替代旧历史。

工程资料/wiki_memory/ 是当前仓库中已跟踪的工程摘要，用作背景。遇到历史描述与源码不一致，以本包最新三份交接说明、源码/README.md、shared/portfolio.ts 和实际测试为准。
