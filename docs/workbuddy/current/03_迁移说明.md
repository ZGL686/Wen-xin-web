# 当前源码与国内迁移说明

## 源码事实

主入口为 src/App.tsx，公共类型和接口字段以 shared/portfolio.ts 为准。完整 API、版本、媒体、大小限制和权限见源码/README.md；不要采用 docs/workbuddy 中 2026-10-25 旧快照的品牌、登录和分类规则。

| 位置 | 作用及交接边界 |
| --- | --- |
| src/、shared/ | React/Three.js 前端和接口类型；收藏为当前源的 localStorage 偏好 |
| worker/api.ts | 真实 API 和浏览器空间权限；Node 与 Worker 复用 |
| worker/index.ts | 原 Cloudflare Worker 入口 |
| server/node-server.mjs | Node HTTP/API/静态服务；默认回环 8788，静态目录 dist/client |
| server/r2-fs-bucket.mjs | 本地持久文件适配；默认 .server-data，仅验证范围内使用 |
| server/r2-cos-bucket.mjs | COS 兼容适配，尚无真实 COS 验收；条件写入靠单进程锁，不能当作跨实例原子写入 |
| vite.config.ts、scripts/vite/ | 原 Cloudflare/Sites 构建链保留；npm run build 同时产出 dist/client 与 Worker dist/server |
| data/works.json、public/ | 五件系统展品和随站资源；无需重跑离线导入脚本 |
| data/derived-previews.ts、data/models/arc01-mouse.glb | 已有鼠标预览关联及服务端模型；仍需原 R2 记录才会出现对应投稿 |
| scripts/prepare-model-decoders.mjs、public/decoders/ | predev/prebuild 从锁定依赖准备本站 Draco/KTX2/STEP 资源及许可 |
| .openai/hosting.json | 交付副本移除了现站 project_id，保留原构建需要的 BUCKET 声明；不是国内发布配置 |

Node 24 可直接运行服务端导入的 TypeScript。npm run start:node 使用源码及 dist/client，不运行 dist/server 中的 Worker。服务目录须保留 worker/shared/data/server，不能只搬一个 mjs 文件。

## 服务端环境变量

| 名称 | 默认或含义 |
| --- | --- |
| FORMSPACE_HOST | 127.0.0.1；默认只供同机反向代理访问 |
| FORMSPACE_PORT | 8788 |
| FORMSPACE_DATA_DIR | 源码/.server-data；未配置 COS 时使用，应设置到持久目录并备份 |
| FORMSPACE_STATIC_DIR | 源码/dist/client |
| FORMSPACE_DERIVED_GLB | 源码/data/models/arc01-mouse.glb |
| FORMSPACE_COS_BUCKET | 配置后选择 COS；未配置则使用文件系统 |
| FORMSPACE_COS_REGION | COS 地域；选择 COS 时必填 |
| FORMSPACE_COS_SECRET_ID、FORMSPACE_COS_SECRET_KEY | 仅服务端安全注入；选择 COS 时必填，包中没有真实值 |

入口直接读取 process.env，没有自动加载 .env；使用进程管理器/系统服务注入，或 Node 24 的 --env-file 机制。不上传实际环境文件。COS 桶应为私有，媒体由 API 鉴权提供。

## API 与数据

- POST /api/session、GET /api/me、PATCH /api/me/profile：初始化/读取/编辑当前浏览器空间。
- GET /api/profiles/:slug、GET /api/works?scope=public 或 mine：公开分享与作者列表。
- GET/POST/PUT/PATCH/DELETE /api/works 及 /:id：作品、不可变版本和作者删除；续版检查 baseRevision。
- PATCH /api/works/:id/publication：检查 revision，选择展示版、公开过程和重要节点。
- GET/HEAD /api/files/...：逐次鉴权，支持 Range/206/416；原件与预览分别授权。

完整路径、字段与错误状态以 README/shared/worker/api.ts 为准。新上传合计 40 MiB、每图 12 MiB、每版最多八图、每作最多 500 版本；原件不限后缀，网页预览仅支持已实现格式，不自动转换 MAX。

R2 数据命名空间为 sessions/、profiles/、records/、versions/、files/。备份须保留对象字节、键、http/custom metadata 与应用使用的条件写入/ETag 语义；文件系统与 COS 适配的物理布局不是简单把 R2 文件夹拷入就能保证兼容。请编写并验证显式导入导出，核对对象数、字节、哈希、版本引用和 owner 映射；先备份并在隔离环境验收，再切换。源码包无远端数据和权限凭据，也未导出私密作品。

HTTPS 使用 __Host-changxu_workspace（Secure、HttpOnly、SameSite=Lax、Path=/、无 Domain）；仅回环 HTTP 开发使用 changxu_workspace。所有写入检查同源 Origin，身份不从客户端可伪造头获取。GET /api/me 只读；新版本不自动改变访客展示版；公开预览不自动授权 MAX 下载。

改域名后原 Cookie 和 localStorage 收藏不能自然跨域，复制服务器数据不能自动恢复原作者管理入口。当前没有恢复码、账号或跨设备恢复。需可验证授权和映射，不得公开旧私密数据或让新浏览器认领旧 owner。

## 验证范围

先在干净交付副本 npm ci，依次 typecheck、npm test、build、test:node，再运行 node scripts/test-derived-build.mjs。包内 06_本地打包验收.json 记录本次实际命令和结果；国内部署步骤和配置示例见 03_国内部署与数据迁移.md。Node 集成测试不等于真实 COS/大陆网络/正式反向代理或浏览器验收。

国内部署验收由 WorkBuddy 在实际环境完成：浏览器交互、HTTPS Cookie、跨浏览器隔离、版本/公开节点/撤回、持久化和重启、并发/失败处理、备份恢复、Range 与原件哈希。现有部分浏览器 QA 脚本使用原工作站浏览器工具，不能声称在其他机器无需配置即可运行。
