# 长序 · WorkBuddy 国内部署交接包

交接日期：2026-11-07。目标是把现有网站部署到面向中国用户的服务环境，保留作品、视觉和真实交互。正式品牌「长序 / CHANGXU」，副题「树莓成熟时」。

1. 解压完整目录，用 WorkBuddy 打开；将 `02_发给WorkBuddy的任务.md` 正文发给它。
2. 先读 `03_国内部署与数据迁移.md` 和 `04_作品资源范围.md`，再运行 `源码/`。
3. 推荐 Node.js 24。在源码目录执行 `npm ci`、`npm run typecheck`、`npm test`、`npm run build`、`npm run test:node`、`npm run start:node`。访问 `http://127.0.0.1:8788/`。
4. `npm run dev` 继续走原 Worker 开发环境；`npm start` 也是本机 Worker。国内 Node 服务使用 `npm run start:node`，后台进程、HTTPS 和持久目录需要配置。

包内包括完整 React + Vite + TypeScript 应用、Node 后端、FS/COS 存储适配、五件内置作品真实资源、三件补充作品原件/预览、工程 Wiki、部署配置示例及逐文件 SHA-256。

当前 Node/本地存储可用于本机验收；COS 是已有待实测适配器，未验证腾讯云生产环境。本包没有购买云资源、部署新站点或导出远端用户数据。`06_本地打包验收.json` 记录本轮实际检查。

作品保存在服务端，作者由浏览器 HttpOnly Cookie 验证。保持免账号，不加入注册登录。换域名不会自动搬走旧 Cookie；搬迁旧私密作品及作者权限需要单独完成安全的数据迁移。收藏也不会自动跨域同步。
