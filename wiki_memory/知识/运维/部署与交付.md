# 部署与交付

当前站点为长序 · 树莓成熟时：https://formspace-sm-3d-studio.h2969351680.chatgpt.site 。Sites 第 4 版发布成功并保留 public 访问、原网址及 BUCKET 绑定。独立应用源码提交 `6e3717bfe4034782a3368ca7a28395d9f93d0e1b`，回执为 `docs/verification/source-formats-20261026.json`。第 3 版免账号功能的回执 `docs/verification/changxu-20261026.json` 及文心第 2 版均保留为历史基线。

第 4 版开放不限后缀归档，原件附件化读取，预览状态按真实资源显示。TypeScript、476 项接口、本地 30 项实际浏览器/R2 与独立生产构建通过。尚无云转换资源，不把 APS proposed 方案写成已部署；方案在 `docs/cloud-conversion-plan.md`，参见 [[决策/ADR-007-原件不限格式与独立云端转换]]。

第 4 版线上 HTML/新包和公开 API 实测成功，但完整私密写入流程因传输中断未完成：首轮 15 项、精确清理一件；第二轮 11 项、提交结果未知，至多一件私密 QA 可能遗留。临时会话已关闭且没有保留凭据，不能冒称已清理或绕过作者权限删除。已停止重试。12 项公开基线资源下载有 9 项字节及哈希通过，三项因网络失败未完成；实际公开数五，包含已有封面但无 modelUrl 的 ARC01 投稿，保持原样。

线上测试器曾把请求诊断写入忽略的失败报告，现已脱敏并扫描，交付和仓库不保留请求头/凭据。后续生产测试须让等待时间覆盖客户端上传超时，超时后保留同一浏览器会话按精确自身标题和 isOwner 查明结果再清理；错误只记录安全 code，不序列化完整请求对象。

第 3 版在生产真实验证免账号首次访问、HTTPS __Host- Cookie、上传模型与封面、私密保存、刷新/同浏览器跨标签编辑、不同浏览器隔离、继续留版、凭据丢失后的草稿保留及作者删除，32 项通过。临时作品始终私密并精确删除；四份 MAX SHA-256、GLB 与 WebP 同时核对通过。手机 390/320 的 75 项检查在当时本地源码运行，无真实设备矩阵承诺。

应用不使用 Sites/ChatGPT 登录，上传和私密历史由 Cookie 空间授权。清除 Cookie、换浏览器/设备或凭据到期无法自动恢复；旧账号数据原样保留但不自动迁移或被新空间认领。具体合同见 [[决策/ADR-006-免账号浏览器创作空间]]。

工程主仓库为 https://github.com/ZGL686/Wen-xin-web.git ，包含源码、原件、Wiki 和交付；Sites 应用仓库仅保存单应用。发布仍在忽略的独立应用 checkout 执行，不把整个根仓库公开成静态资源。本轮复用既有依赖（锁文件未变），独立副本通过类型、476 项接口和生产构建后由 helper 普通推送、打包、保存再部署；凭据只在会话内存及隐藏 stdin 传递。

formspace/.openai/hosting.json 保持原项目 ID、r2:BUCKET、d1:null，输出仍为 dist/client 和 dist/server。GitHub 推送与网站发布分开验证。

历史 WorkBuddy ZIP 保持旧哈希和 2026-10-25 内容，不包含长序与免账号功能。新接手使用当前 main、formspace/README.md 及 shared/portfolio.ts；源码不是远端 R2 数据备份。国内托管和存储迁移尚未完成，换域名必须考虑 Host Cookie 无法自动搬迁，不能把复制前端当作完整迁移。
