# 部署与交付

## 原站与访问

原站地址为 https://formspace-sm-3d-studio.h2969351680.chatgpt.site 。这是 2026-10-25 的发布及验收记录；本页不表示已经在 2026-10-26 再次联网确认可用性。后续报告当天状态时必须另行验证并记录日期。

现有应用的权限合同为公开浏览和下载、登录后提交、作者删除自己的新增作品。初始四件作品通过源码维护，删除接口不接受内置条目。实际托管访问策略由平台控制，不能只凭前端文案推断实时权限。

## 两个仓库边界

工程主仓库为 `https://github.com/ZGL686/Wen-xin-web.git`，在仓库根目录维护网站、资产、交付与 Wiki。它与 Sites 的应用源码仓库承担不同职责。

原站身份和存储绑定保存在 `formspace/.openai/hosting.json`；当前声明 `r2: BUCKET`、`d1: null`。应用生产构建输出位于 `formspace/dist/client` 和 `formspace/dist/server`，生产 Worker 依赖托管方提供的静态资源与 R2 绑定。

未来更新原 Sites 网站时，应复用该 manifest 对应的同一应用身份，在独立应用 checkout 中执行 Sites 源码同步、打包和部署。不要直接在根目录工程仓库运行面向单应用的 Sites 源码 helper，也不要把整个工程仓库推成原站应用源码。GitHub 工程同步成功不代表网站已经重新发布。

## 交付包

保留 `deliverables/FormSpace_WorkBuddy_China_20261025.zip` 和对应 `.zip.sha256`。ZIP 保存交接时的源码、初始四件作品、真实预览资源、界面参考及迁移说明，是历史交付物。展开目录仅供本地检查，不作为第二份持续维护源码。

接手包移除了现站发布身份、凭据、Git 历史、依赖目录和本机缓存。它仍是 Cloudflare Worker/R2 原版，国内服务端和登录迁移待完成。包内没有导出远端后续投稿或远端用户数据。

## 验证与恢复边界

- 验证网站源代码时进入 `formspace/`，使用 [[知识/流程/开发验证与国内迁移]] 的命令。
- 验证交付完整性时，对 ZIP 校验对应 SHA-256；核对原件时使用 `formspace/public/portfolio/verification.json` 中记录的哈希。
- `npm start` 仅运行本地已构建 Worker；直接打开静态 HTML 或只托管客户端文件不能恢复完整上传服务。
- 源码和 ZIP 备份不等于远端 R2 数据备份；恢复后来投稿必须同时恢复作品记录、文件及其 URL 映射。
- 凭据只通过平台或受控本地环境传递，不写入 Wiki、源码、交付包或命令摘要。
