# 部署与交付

## 当前站点

文心 · 树莓成熟时：https://formspace-sm-3d-studio.h2969351680.chatgpt.site 。Sites 第 2 版于 2026-10-26 发布成功，保留原网址与 public 访问策略；Site 显示标题已更新。生产源码提交为 `8c335c9ba3e620961523741ba63cf6db3d7dc135`。准确的项目、版本和部署 ID 及验收结果保存在 `docs/verification/wenxin-20261026.json`。

本次线上匿名检查包含品牌、作品列表、三维真渲染、标签筛选、个人展示页、登录入口、手机菜单，以及四份 MAX 原件 SHA-256 与 GLB/WebP 读取。作者新建/编辑/公开/撤回及媒体权限由相同源码在本地 Vite + 实际 Miniflare R2 验证；未执行第三方真实账号的线上自动登录或生产测试投稿。

当前公开浏览无需登录，保存作品需 Sites/ChatGPT 登录；新作品和新版本默认私密，作者选择展示版和过程节点。系统展品四件保持公开下载，任意账号不可认领。新增作品原件下载默认关闭，网页预览资源随选定公开节点授权。国内后端和登录迁移尚未完成。

## 两个仓库边界

工程主仓库为 `https://github.com/ZGL686/Wen-xin-web.git`，根目录同时维护网站、原件、交付与 Wiki；它与 Sites 应用源码仓库承担不同职责。

站点身份和存储绑定位于 `formspace/.openai/hosting.json`，声明 `r2: BUCKET`、`d1: null`。构建输出 `dist/client` 与 `dist/server`，后者仍为 Cloudflare Worker，需要托管静态资源和 R2 绑定。

本轮在忽略目录 `.local-history/wenxin-site-release/` 准备独立应用 checkout；按锁文件安装依赖，核对源码与公开资产相同后执行类型、接口检查和生产构建，经 Sites helper 普通推送、打包、保存并部署。不要把工程根目录整体交给单应用 helper，不把原件/Wiki 当作站点公开静态资源。凭据仅经会话内存和隐藏 stdin 传递。

## 历史交付包与新版接手

`deliverables/FormSpace_WorkBuddy_China_20261025.zip` 及其 SHA-256 保持不变，是旧形间站点的历史快照，不包含本轮新增的文心品牌、个人空间与私密版本能力。展开副本不作为第二份持续维护源码。

新版接手以工程仓库 `main`、`formspace/README.md` 和 `formspace/shared/portfolio.ts` 为准。`docs/workbuddy/` 保留旧包说明并标明历史范围。旧包未完成国内迁移，也未导出后来远端投稿。

## 运行与恢复

- 进入 `formspace/` 运行安装、类型检查、接口测试和构建；工具链与 Node 版本要求见该目录 README。
- 单独打开 HTML 或只托管客户端不能恢复上传、身份或私密文件授权。生产服务需保留 Worker/R2 或按新版合同迁移服务端。
- R2 现使用 profiles/records/versions/files，恢复后来投稿需同时恢复索引、快照、文件和作者映射。源码/ZIP 不是运行数据备份。
- MAX 原件路径现为 `assets/3d source/`；网页四件基线以 `formspace/public/portfolio/verification.json` 核对。网页模型不能保证专业软件材质完全一致。
- 本次手机测试使用 Edge 的 390/320 视口，不等于所有真实 iOS/Android 设备兼容性验收。
