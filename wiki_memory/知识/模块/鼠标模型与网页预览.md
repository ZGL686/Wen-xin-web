# 鼠标模型与网页预览

## 原件和转换

用户要求在完成电脑网页端时，把已有 ARC01 鼠标原件转换为网页预览。使用本机 3ds Max 2026 只读打开 `assets/3d source/ARC01_Mouse_3dsMax2026.max`，与已有公开作品原件比对 SHA-256 一致：`e9918e40d1abb39338f38e70774681983e97ecdfe4320e7e9d6d24c021602bbb`，9,101,312 字节。转换不保存或改写 MAX，没有使用 Blender 重建。

`assets/pipeline/export-mouse-preview.ms` 求值真实网格；复用 `assets/keyboard-rapoo-reference/world_mesh.ms` 处理世界坐标，再以支持显式输入/输出路径的 `export_web.py` 输出 GLB。默认键盘管线保持兼容，未重新生成或修改已有键盘资产。原生读回验证通过，场景为厘米；82 个网格、131,144 个三角形、9 种网页材质，无外部位图。网页保留几何与基础颜色/发光，PBR 材质是原生材质的近似转换，不承诺专业渲染器效果完全一致。

模型为 `formspace/data/models/arc01-mouse.glb`，3,464,316 字节，SHA-256 为 `7c4b3b7eb558b4869e0bfb5d7b2183dc01eb71e4427daa7becf327d2943670eb`。单位米、Y 向上，包围盒约 0.07490 × 0.04210 × 0.12769 米。验证依据在 `docs/verification/mouse-conversion-20261102.json`，二进制使用 LFS。

## 关联已有作品

已有 R2 作品 ID 为 `f0b4e73e-169e-41a1-bc3f-4505be3d802d`。`data/derived-previews.ts` 登记已核对的两个源版本、原件地址/名称/字节数和衍生模型。读取对应不可变快照时补充 modelUrl，不改写 R2 作者、封面、历史、展示指针或公开节点，不另建系统展品。已有作者明确提供的 modelUrl 优先；不匹配的版本或原件不自动关联。

后续作者普通保存时可沿用预览；明确清除 model 或更换 source 继续遵守原规则。注册表只为两个已核实的旧版本补充预览，不能按作品 ID 给未来所有版本强制补回。source 哈希由离线转换回执核对，不在每次预览时读取整个 MAX。

当前鼠标及原件本已公开，衍生模型按项目持续同步授权随源码进入公开工程仓库。站内撤回只关闭网站接口，不会撤销他人已取得的副本或仓库文件。未来私密作品的自动转换必须使用私密对象存储，不把其结果登记到公开源码或内联发布包。

## 权限与部署

预览经 `/api/files/:work/model.glb` 提供。接口先校验实际记录及作者/当前公开节点，再读取 Worker 内的模型；支持 GET/HEAD/Range，响应 private/no-store、Vary: Cookie，不设置附件下载。撤回公开后匿名访客不能继续读取。

`worker/derived-model.ts` 通过 Vite 的服务端 inline 导入 GLB，第一次通过鉴权的预览请求才解码，后续复用内存；字节不进入客户端代码或 public。当前只是约 3.5 MB 的已核实单件预览，更多或更大模型应迁入专用私密对象存储，不继续扩充 Worker 内联模型。

线上验证发现现托管会优先直出已有静态资源，不能靠 `run_worker_first` 和 Worker 路径拦截保护 public 文件。因此不可把模型放在 public；`scripts/test-derived-build.mjs` 在发布前核对源模型哈希、Worker 包含正确模型且全部客户端产物均无二进制或 base64 副本。`protected-assets.ts` 继续拒绝旧候选目录及编码别名；生产返回 SPA HTML 的未知路径也不能泄露模型字节。权限验收必须验证实际部署，不能仅凭本地 Worker 判断成功。

API 回归验证公开/撤回/不同浏览器/作者、派生预览沿用和清除、源不匹配、已有预览优先、原快照未改写及原始路径拦截。`scripts/test-mouse-preview.mjs` 本地使用公开详情的客户端夹具和真实 GLB，不写入生产记录；生产模式直接验证原作品、真实文件、交互、HEAD/Range 和原始地址拦截。

这是针对已有单件作品的离线转换，通用 MAX 云转换仍未接入，见 [[决策/ADR-007-原件不限格式与独立云端转换]]。桌面查看器见 [[知识/模块/浏览器三维查看器]]。
