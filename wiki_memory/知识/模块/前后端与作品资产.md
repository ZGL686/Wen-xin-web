# 前后端与作品资产

## 模块关系

网站源码位于仓库的 `formspace/`，采用 React 19、Vite 8、TypeScript 与 Three.js。当前服务端仍为 Cloudflare Worker，新增作品及文件保存到 R2；未使用 D1。构建配置保留 `sites()` 与 Cloudflare 插件。

| 入口 | 职责 |
| --- | --- |
| `formspace/src/main.tsx` | 挂载 React 应用 |
| `formspace/src/App.tsx` | 首页、作品库、详情、上传、关于页；搜索、分类、排序、收藏、分享与管理交互 |
| `formspace/src/styles.css` | 共享视觉样式和响应式布局 |
| `formspace/src/ModelViewer.tsx` | 延迟加载 Three.js、GLB/OBJ/STL；旋转缩放、自动旋转、线框、图片回退及资源释放 |
| `formspace/worker/index.ts` | 将 `/api/*` 分派给接口，其余请求交给静态资源绑定 |
| `formspace/worker/api.ts` | 身份读取、上传校验、R2 读写、作品列表与作者删除权限 |
| `formspace/data/works.json` | 初始四件作品的条目、资源地址和几何说明 |

页面使用 `/#/`、`/#/works`、`/#/work/:id`、`/#/upload`、`/#/about`。详情链接包含 hash，可直接分享。收藏保存在当前浏览器的 `formspace-favorites`，不会同步为服务端作品数据。接口暂时不可用时，前端显示内置作品并明确提示连接异常。

## API 与持久化

| 方法与路径 | 合同 |
| --- | --- |
| `GET /api/works` | 公开返回 `{works, user}`；新增记录在前、内置条目在后；不返回内部 `storageKeys` 或他人的 `ownerId` |
| `POST /api/works` | 登录并通过同源校验后接收 multipart；成功为 `201 {work}`，失败为 `{error}` |
| `GET /api/files/:uuid/:file` | 读取文件，提供 MIME、`nosniff` 和缓存头；源文件保留原名称下载 |
| `HEAD /api/files/:uuid/:file` | 与 GET 相同的文件元数据，不返回内容 |
| `DELETE /api/works/:uuid` | 仅作者可删除自己的新增作品；成功为 `{ok:true}`；内置条目不能经此接口删除 |

R2 的 `records/{uuid}.json` 保存作品记录，`files/{uuid}/source.ext` 与 `files/{uuid}/image-N.ext` 保存源文件和图片。只有全部文件保存成功后才写入作品记录；记录写入失败会回滚已上传文件。缺少存储绑定时返回 503，不返回假成功。

Work 的主要字段为 `id`、`title`、`subtitle`、`category`、`description`、`tags`、`date`、`fileName`、`fileSize`、`fileUrl`、`modelUrl`、`coverUrl`、`images`、`format`、`builtIn`；内置资产另有对象数、尺寸等信息。`ownerId` 仅向当前作者返回，`storageKeys` 仅供服务端内部使用。

## 上传与预览边界

- 每件作品最多一个源文件、八张图片；至少提供源文件或图片中的一项。
- 单张图片不超过 12 MiB，文件合计不超过 40 MiB；接口另为 multipart 包装保留 256 KiB 限额。
- 标题为 1–80 字；当前前端介绍限制 3000 字，接口限制 4000 字；标签按中英文逗号分隔，最多八个、每个最多 24 字。
- 分类为产品设计、家具设计、空间建筑、其他创作。
- 源文件支持 MAX、BLEND、FBX、OBJ、STL、GLB、GLTF、ZIP；图片支持 PNG、JPG/JPEG、WebP、AVIF、GIF，并执行服务端文件签名校验。
- GLB、单文件 OBJ、STL 支持网页三维预览。MAX、BLEND、FBX、GLTF、ZIP 可归档下载；存在外部贴图等依赖的工程不会自动在网页还原。

## 初始资产

初始作品为玉石灯、云朵熊沙发、柜子和房屋。原始 MAX 保存在 `assets/source/`，转换资料在 `assets/pipeline/`，网页使用 `formspace/public/originals/` 与 `formspace/public/portfolio/` 的交付副本。真实几何由原生场景离线转换，网页材质为基础色近似；原始材质和灯光效果以 MAX 文件为准。

`formspace/public/portfolio/verification.json` 记录源文件哈希、源尺寸、可见网格数、三角面数及转换说明。浏览模型以最长边三个查看单位归一化，物理尺寸应读取验证清单，不能从查看器缩放值推断。
