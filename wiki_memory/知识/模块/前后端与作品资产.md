# 前后端与作品资产

## 模块关系

网站源码位于 `formspace/`，采用 React 19、Vite 8、TypeScript 与 Three.js。当前服务端为 Cloudflare Worker/R2，未使用 D1；构建保留 `sites()` 与 Cloudflare 插件。本文记录当前源码和本地验证，不表示该版本已线上发布。

| 入口 | 职责 |
| --- | --- |
| `formspace/src/main.tsx`、`src/App.tsx` | 挂载应用、路由、公开列表与登录状态 |
| `formspace/src/PortfolioViews.tsx` | 首页、分类作品库、个人空间与关于 |
| `formspace/src/WorkForm.tsx` | 新建、编辑、媒体选择、继承已有内容、过程说明和版本保存 |
| `formspace/src/WorkDetail.tsx` | 版本回看、展示版/公开历史/重要节点、作者管理 |
| `formspace/src/ModelViewer.tsx` | 延迟加载 GLB/OBJ/STL，旋转、缩放、线框和资源释放 |
| `formspace/src/MediaPreview.tsx`、`src/media-cover.ts` | 多媒体预览及浏览器可处理资源的封面提取；失败不阻止保存 |
| `formspace/shared/portfolio.ts` | Snapshot、Work、Version、Profile 与 API 合同 |
| `formspace/worker/index.ts`、`worker/api.ts` | 静态资源/接口分派、身份、版本持久化、公开投影和文件授权 |
| `formspace/data/works.json` | 四件系统展品的原始条目和几何说明 |

页面使用 `/#/`、`/#/works`、`/#/space`、`/#/u/:slug`、`/#/work/:id`、`/#/upload`、`/#/edit/:id`、`/#/about`。作品详情可按版本回看；“回看历史”不等于自动恢复旧版为最新稿。收藏保存在本设备的 `formspace-favorites`，不会变为服务端作品记录。

## API 与数据视图

| 方法与路径 | 合同 |
| --- | --- |
| `GET /api/me` | `{user, profile}`，匿名为空用户 |
| `PATCH /api/me/profile` | 作者修改名称、简介；稳定 slug 不变 |
| `GET /api/profiles/:slug` | `{profile, works, user, isOwner}`，仅该空间公开展示作品 |
| `GET /api/works?scope=public` | `{works, user, profile}`；可按 `profile=slug` 限定；只读取已选展示版 |
| `GET /api/works?scope=mine` | 仅登录作者的最新作品快照，包括私密作品 |
| `GET /api/works/:id` | `{work, versions, user, isOwner}`；作者取得完整历史，访客只得展示版及明确公开的历史节点 |
| `POST /api/works` | JSON 或 multipart 保存私密新作，成功 201 |
| `PUT/PATCH /api/works/:id` | 提供 `baseRevision`，保存同作品的新版本；缺省内容沿用最新稿 |
| `PATCH /api/works/:id/publication` | 提供 `revision`，更新展示、公开历史、重要节点；不另建内容版本 |
| `GET/HEAD /api/files/:work/:version/:file` | 权限校验后的文件读取，兼容旧地址，支持 Range/206/416 |
| `DELETE /api/works/:id` | 作者删除整作与版本文件；系统展品不可修改或认领 |

Snapshot 保存标题、方向/标签、介绍、文字内容、过程/困难/解决/心得、状态及媒体引用。Work 是当前允许查看的平面快照，并附 revision、版本指针、作者空间及可见性；Version 为一次成功保存的快照。公开响应不含私密版本 ID/真实总数、最新私密指针、他人的 ownerId 或内部 storageKeys。

新作先私密保存；以后主动保存只增加私密版本，不自动替换公开画面。仅选公开展示版不会公开其过程字段；只有版本被列为明确公开的历史节点时，过程信息才向访客返回。展示版设为空会隐藏整件作品及其文件，作者历史仍在。

## R2、并发与文件权限

R2 的 `profiles/{slug}.json` 保存作者资料，`records/{work}.json` 保存 schema 2 索引，`versions/{work}/{version}.json` 保存快照，`files/{work}/{version}/{role}.ext` 保存资源。索引的展示版、公开节点和重要节点与内容快照分开维护。

文件读取逐次查作品权限与被授权版本引用；不能仅凭已知 URL 读取私密资源，也不能靠传入任意 fileUrl/modelUrl/ownerId 冒用其他作品。新资源的 source 原件与 model 预览为不同角色/地址；原件下载需该公开版本明确允许，WebGL 预览字节本身可被浏览器取得。响应使用 `private, no-store`，Range/HEAD 和普通 GET 先执行相同权限检查。

先写资源和快照，再用 R2 条件写提交索引。过期 revision 或并发竞争返回 409，不覆盖另一窗口内容；失败会补删未提交资源。若索引写入回执不明确，先读回判断是否已提交；无法确认时保留资源，不破坏可能已成功的版本。缺存储绑定返回 503，不产生假成功。

旧版公开单记录兼容为一份历史快照，保留原 owner、展示和下载行为；第一次编辑后保存为版本结构，旧公开指针保持。初始四件映射为“三维”，旧产品设计、家具设计等分类成为标签；系统展品不属于首先登录的用户。

## 输入与资源边界

- 一个主方向：交互、影视、三维、其他；作者标签按中英文逗号或数组去重，最多八个、每个 24 字。
- 首次名称、方向及至少一份内容必填；内容可以是文字、图、文件、视频、音频或 HTTPS 体验链接。后续可沿用已有文件。
- `source` 支持 MAX、BLEND、FBX、OBJ、STL、GLB、GLTF、ZIP；`previewModel` 支持 GLB、单文件 OBJ、STL；各最多一个。
- `images` 最多八张，单张 12 MiB，支持 PNG/JPG/WebP/AVIF/GIF；第一张默认封面，可由表单提取后的图片补充。
- `video` 与 `demoVideo` 支持 MP4/WebM，各一个；`audio` 支持 MP3/WAV/OGG/M4A，一个。图、音视频执行格式签名校验。
- 每次新上传文件合计 40 MiB，multipart 包装另留 256 KiB；JSON 请求 128 KiB。标题最多 80 字，介绍与每项过程字段 4000 字，文字内容 20000 字。
- `previewStart`、`previewEnd` 为选填非负秒数，结束晚于开始；API 不规定固定预览时长。
- 当前实现每作最多 500 个版本；无变化的主动保存也留版。状态为 `in-progress`/`final`，与私密/公开独立；没有后台自动保存或用户电脑文件同步。
- 原始 MAX/BLEND/影视工程不会自动由 Worker 转换运行；外部 HTTPS 体验能否嵌入受目标网站和浏览器策略限制，ZIP 归档不等于执行代码。

## 初始资产

初始作品为玉石灯、云朵熊沙发、柜子和房屋。原始 MAX 保存在 `assets/3d source/`，转换资料在 `assets/pipeline/`，网页使用 `formspace/public/originals/` 与 `formspace/public/portfolio/` 的交付副本。真实几何由原生场景离线转换，网页材质为基础色近似；原始材质和灯光效果以 MAX 文件为准。

`formspace/public/portfolio/verification.json` 记录源文件哈希、源尺寸、可见网格数、三角面数及转换说明。浏览模型以最长边三个查看单位归一化，物理尺寸应读取验证清单，不能从查看器缩放值推断。
