# 卡通房子重建与作品替换

用户于 2026-11-05 明确要求将 `assets/3d source/房子3d.max` 重新建为卡通可爱风，并自动替换对应旧文件和长序已有房子作品，交付可二次修改的 MAX，同时上传到个人作品。这是针对该房子的明确替换授权，优先于通常不改写原件的保护规则；不扩展到其他作品。

旧房子及其 GLB、PNG、WebP、旧验证记录已留档于 `archive/house-before-cute-20261105/`，原 MAX SHA-256 为 `850C56242F2FC6ACC7E3D4FFDFCC8E13177ACD9F797BC1117841981B21FB74F3`。原房在真实 Max 中重新打开成功，有两个可见网格与一个空几何对象；新版以交叉坡屋顶轮廓为识别起点。

本地模型“莓糖小屋”已完成：奶油墙体、草莓色屋顶、圆润门窗和小庭院，使用本机 3ds Max 2026.2 原生批处理。制作配方在 `assets/house-cute/pipeline/`，交付目录为 `deliverables/Cute_House_2026/`；`3d.max` 是真实原生场景。独立从磁盘重新打开检查通过，330 个部件全部为 Editable Poly，19 种纯色材质、六个模型层，98,280 个三角面，无空部件、缺材质、坏坐标或外置位图。单位厘米，边界尺寸为 100 × 115 × 60.375 厘米；两张 1600×1400 PNG 来自实际 Max 渲染并已视觉检查。

网页 GLB 来自同一场景实际求值网格，330 个对象均使用原生面角法线；导出时跳过 62 个退化三角面，最终 98,218 个三角面、2,657,096 字节，无外部资源。坐标转换为米与 Y-up；GLB 的材质和 Max 渲染有差异，不承诺像素一致。原生回执为交付目录的 `native-verification.txt` / `.json`，GLB 回执为 `House.verification.json`。最终整包 `deliverables/Cute_House_3dsMax2026_Package.zip` 为 10,062,908 字节，CRC、11 个条目及逐文件 SHA 检查通过；本地回执为交付目录的 `package-verification.json`，文件清单为 `SHA256SUMS.json`。

网站已有房子是 ID `house` 的内置系统展品，资源为 `formspace/public/originals/house.max`、`formspace/public/portfolio/house.glb` 和 `house.webp`，不能通过个人作品写接口认领或修改。本地交付完成后需更新这些副本及验证基线并重新发布站点。个人作品须沿用原用户浏览器凭据另行上传，默认私密；不新造作者会话，也不把 GitHub 推送当作网站发布。当前线上替换及个人上传仍待最终回执，本页尚不表示已经上线或个人上传成功。
