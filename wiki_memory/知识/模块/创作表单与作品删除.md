# 创作表单与作品删除

用户要求显式删除入口并降低创作页文字密度。第 9 版保持原风格、React/Vite、所有媒体与私密版本合同，未变更 Worker API 或 R2 结构。通用 MAX 云转换按用户要求暂缓。

## 删除入口

`DeleteWorkButton.tsx` 共用于“我的空间”的自有作品卡片与作品详情顶部，确认前不发 DELETE。原生 dialog 提供聚焦、键盘范围和 Escape；默认聚焦“保留作品”，显示实际标题、版本数、文件与历史永久删除说明，公开作品另说明分享链接失效。请求中禁用重复确认和取消，失败保留弹窗并显示错误。

确认收到服务端 ok 后，App 过滤公开列表和收藏引用并刷新；CreatorSpace 过滤个人列表，详情返回个人空间。没有乐观假删除、回收站或撤销恢复。取消不删除，作品普通编辑仍通过新增版本保留历史。

按钮只为 isOwner 且非 builtIn 的记录显示；服务端 Cookie 权限校验继续拒绝跨空间管理。系统展品与其他作者作品不显示删除入口。清除 Cookie、换浏览器或旧账号空间不能凭公开 URL 自动认领。旧版隐藏在详情底部折叠项里的管理区已移除。

原生 dialog 位于作品卡片内，但使用顶层显示。确认段落必须显式清除卡片摘要的截断、行数和高度限制；不要让 `.card-info p` 的省略样式截断删除警告。入口及弹窗样式位于 `work-actions.css`。

## 精简创作页

`WorkForm.tsx` 的文件、模型资源包、封面、文本和版本提交逻辑保留，主要重写展示区域。默认只有基本信息和作品内容两张主卡片：名称/主方向必填，至少一份内容。文件、图片、文字、链接切换使用同一草稿状态，不丢弃已输入内容；编辑时按已有媒体选择初始面板。

作品介绍（含标签和副题）、过程记录、更多设置默认折叠。三维配套文件/文件夹、演示视频和影视片段仍可展开选择，所有隐藏文件输入保持挂载。图片继续可重排首张封面，沿用/移除旧附件规则不变。更多设置包含创作中/定稿、自动封面与独立原件下载开关。

右侧摘要显示所选封面、名称、方向、状态、目标版本及私密保存按钮，窄屏顺排到下方。浏览器空间权限说明保留在可展开区域，避免重复占用首屏。样式在 `work-form.css`，作用于 creation-editor，不改变其他页面主题。

## 检查

`scripts/test-creation.mjs` 使用本机 Edge 和现有 Playwright。验证混合内容上传、选填故事、面板切换、封面重排、原件字节、无重传续写、作者/其他浏览器权限，以及删除取消、确认、错误、收藏、刷新、详情返回和三种宽度。

本地使用真实 R2 模拟器，并测试一件临时公开作品删除和 503 重试；生产只创建两件本次私密 QA，保留同一作者会话，按精确标题/ID 清理，不公开 QA、不处理旧测试或真实作品。失败时先在当前空间查明同一标题结果，再清理，避免重复创建或销毁凭据后失去确认能力。

相同 1440×1000、本地字体条件下，初始可见文字（去空白字符）978 → 305，主区域高度 2728 → 1293 像素。具体检查结果与上线来源以 `docs/verification/creation-delete-20261102.json` 为准。相关 [[决策/ADR-004-创作过程与私密版本历史]]、[[当前状态/系统架构]]、[[知识/运维/部署与交付]]。
