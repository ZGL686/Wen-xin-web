# 独立收藏页

用户指出收藏后没有单独界面。旧 Collection 只有当前列表内的收藏筛选，无法集中查看其他列表或自有私密作品。第 10 版新增 `/#/favorites`，主导航和各列表工具栏均可进入，沿用长序的配色、字体和真实作品卡片。

`src/Favorites.tsx` 复用 Collection/WorkGrid，默认按最近收藏排列，支持搜索、四方向、汇总去重标签、排序、封面预览、进入详情和取消收藏。切换方向仍清空标签。空收藏提供展厅入口，筛选无结果可以返回全部收藏。原列表内的收藏筛选按钮已替换为进入全局收藏的链接。

## 保存与权限

继续使用浏览器 localStorage 的 `formspace-favorites`，只存作品 ID，不迁移或清空旧记录；读取去重并忽略空字符串和非字符串，损坏 JSON 安全回退。App 监听同源 storage 事件，使同一浏览器其他标签页更新数量和爱心。收藏不上传到服务器、不跨浏览器或设备同步，清除站点数据会丢失偏好。

收藏页通过原 `GET /api/works/:id` 接口读取当前允许查看的作品，最多四请求并行；包含当前作者自己的私密作品，完全沿用 Cookie 授权。请求随依赖变化或离页取消，结果按当前 owner 隔离，不能凭收藏 ID 查看其他空间私密内容。取消收藏即时移除卡片和更新计数；详情的收藏操作、原作品删除后的引用清理继续有效。

403/404 表示暂不可查看，保留收藏引用并明确说明可能撤回、删除或空间不同，不显示无权读取的元信息；503/网络故障单独计数并允许重试，不当成空收藏，不丢弃已成功加载的其他作品。不新增作品、版本、权限或后端结构。

## 验证与维护

`scripts/test-favorites.mjs` 使用本机 Edge 与既有 Playwright。本地 31 项、生产 29 项检查通过，包括旧记录、刷新、两标签页双向更新、筛选/排序、取消与空状态、部分/全部失败重试、不可见内容和布局。生产模式只读作品和修改隔离测试浏览器的收藏偏好；本地另新建一件私密夹具，跨浏览器授权验证后精确删除。

TypeScript、独立应用构建及受保护鼠标模型无静态副本检查通过。API 未变更，本轮没有重跑整套 542 项接口检查。1280/1920 桌面和 850/390 窗口没有横向溢出，不代表实体设备矩阵验收。具体来源与结果见 `docs/verification/favorites-20261103.json`、[[知识/运维/部署与交付]]。
