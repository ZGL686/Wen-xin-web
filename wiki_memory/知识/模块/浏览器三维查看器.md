# 浏览器三维查看器

## 使用与文件

公开作品与作者私密详情共用查看器，作品列表只在用户点击预览时挂载模型。支持 GLB、glTF、OBJ、STL、FBX、STEP/STP，以及只包含一份主模型和配套文件的预览 ZIP。缺少 glTF 的 .bin/纹理、OBJ 的 MTL 或 FBX 外置纹理时，使用上传页“选择模型与配套文件”或“选择模型文件夹”；不要只上传其中一个文件。多文件会生成保留相对路径的预览 ZIP，可继续附上独立原件。

新作品默认私密。预览与原件分角色、分地址鉴权；公开展示不自动开放源文件或旧版本。普通原件 ZIP 仍是归档，只有明确提供为 previewModel 的模型包才参与解析。MAX/C4D/其他原生格式仍需另附可预览模型，通用云转换未部署。

## 操作与性能

左键拖动旋转，右键拖动平移，滚轮缩放；双击命中模型表面时平滑聚焦局部。居中保持当前方向并适配全模型，重置恢复默认方向与尺度而不重新请求模型。全屏使用浏览器原生接口；不支持时采用覆盖视图，有退出按钮与 Escape。方向键、加减键及 R/Home 可操作相机。

触屏支持单指旋转、双指捏合缩放、双指平移和双击聚焦。手动操作暂停自动旋转，尊重系统减少动态效果偏好。相机静止时停止 RAF，离屏或页面隐藏时暂停；动态像素比有上限，50 万三角形以上降像素比并关闭动态阴影。当前不提供任意超大装配的 FPS 或内存保证。

当前主要验收目标为电脑浏览器，不要求手机 App 或实体手机矩阵。首页复位通过 resetToken 调整相机，不重建 Canvas 或重新请求模型；手动操作同步暂停按钮状态。`scripts/test-desktop.mjs` 验证 1280×720、1366×768、1920×1080 的首页/作品库/详情/上传页，以及鼠标、键盘、全屏、复位不重复加载。已有鼠标的真实 MAX 离线转换与权限关联见 [[知识/模块/鼠标模型与网页预览]]。

## 模块与资源

- `src/ModelViewer.tsx`：Three 场景、camera-controls、点击拾取、全屏、资源释放和按需渲染。
- `src/model-loader.ts`：格式分派、受限本地资源解析、ZIP 限制、STEP Worker 生命周期和统一释放。
- `src/media-cover.ts`：与查看器共用加载器生成选填封面，8 秒取消，失败仍可归档。
- `public/decoders/step-worker.js`：STEP 曲面网格化，不占主 UI 解析线程，完成即终止。
- `scripts/prepare-model-decoders.mjs`：从锁定依赖准备本站 Draco/Basis/OCCT 文件及许可证；构建自动执行。

解码器生成目录不入 Git；部署必须执行 prebuild 并发布生成的静态文件，WASM 建议以 application/wasm 提供。原件 40 MiB、ZIP 展开 80 MiB/256 项和 STEP 120 秒上限分别约束上传、解压与解析。

## 验证

`npm test` 运行接口和权限回归；`npm run typecheck` 检查类型。`node scripts/test-viewer.mjs` 以本地服务器进行鼠标/全屏/触屏、多格式与真实私密上传/封面检查，精确清理本次作者测试记录；传入生产 URL 时只做公开读取和客户端夹具，不写作品记录。使用本机 Edge 和已提供的 Playwright 运行时。

Draco 使用 Khronos 官方 Box 示例，STEP 使用锁定 occt-import-js 附带的立方体，FBX/GLB 使用本项目键盘；glTF/OBJ/STL 和模型包夹具由检查脚本生成。触屏为浏览器模拟，不代表已完成实体手机矩阵或超大装配压力测试。结果以该轮发布回执为准，见 [[知识/运维/部署与交付]]、[[决策/ADR-008-浏览器多格式三维预览]]。
