# 青花瓷壶模型与个人上传

本次用户提供青花牡丹、朱红口沿茶壶的单视图，要求可二次修改的 `3d.max` 及长序个人作品。模型使用本机 3ds Max 2026.2 原生创建，实际交付位于 `deliverables/Porcelain_Teapot_2026/`。没有用标准Utah茶壶代替参考形状，也没有把GLB/OBJ改名为MAX。

13个独立Editable Poly部件包括空心壶腹、足圈、独立盖、壶钮及尖、空心弯嘴、环形把手和朱红装饰。场景单位厘米，整体约31.8×18.5×21.2厘米，106224个三角形。单张照片不能确定的背面、纹样和尺寸为比例补全，不是精确工业测绘；单件内部和交接没有做制造/流体通路验证。

牡丹是新生成的1254×1254白底青花PNG，不是去除参考照片水印；可替换外置贴图 `peony_albedo.png`，应与MAX一起保留。网页GLB来自Max真实求值网格和UV，含4种材质及内嵌纹理，无外部资源。网页PBR与Max标准材质效果会有差异。

`assets/teapot/pipeline/` 保存可重建配方、真实网格导出与GLB打包、独立重新打开检查脚本；中间生成MS、网格JSON、日志和官方流程副本忽略。DCC-MCP本次没有可调用注册实例，未声称实时MCP验收；实际使用Max原生批处理创建、渲染和重新打开，报告为交付目录的 `native-verification.txt`。复用调查见管线README。

上传复用用户已经打开的IAB空间，未创建替代作者会话或导出Cookie。作品ID为 `5f35ce63-e3b3-4d8c-b167-fa5935983686`，作为个人R2作品保存，不改系统展品列表，不需要重新发布Sites。原件使用含MAX、贴图和检查文件的ZIP，模型单独上传GLB，封面为同一实际Max模型的两角度渲染。只上传MAX会遗漏配套贴图，因此交付同时提供MAX链接和推荐整包。

上传和修订保持同一作品，保留私密历史；最终实际状态与浏览器验收见 `docs/verification/teapot-20261105.json`。通用MAX云端自动转换仍未接入，这次是本机导出已知茶壶；不能据此宣称任意新MAX自动预览。
