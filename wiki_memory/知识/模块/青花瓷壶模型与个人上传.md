# 青花瓷壶模型与个人上传

用户提供青花牡丹、朱红口沿茶壶的单视图，要求可二次修改的 `3d.max` 及长序个人作品。模型使用本机 3ds Max 2026.2 原生创建，原件和牡丹贴图放在 `assets/3d source/Porcelain_Teapot_2026/`。导出模型为 `assets/pipeline/Teapot.glb`，原生渲染位于 `assets/renders/teapot/`。

13个独立Editable Poly部件包括空心壶腹、足圈、独立盖、壶钮及尖、空心弯嘴、环形把手和朱红装饰。场景单位厘米，整体约31.8×18.5×21.2厘米，106224个三角形。单张照片不能确定的背面、纹样和尺寸为比例补全，不是精确工业测绘；单件内部和交接没有做制造/流体通路验证。

牡丹是新生成的1254×1254白底青花PNG，不是去除参考照片水印；可替换外置贴图 `peony_albedo.png`，应与MAX一起保留。网页GLB来自Max真实求值网格和UV，含4种材质及内嵌纹理，无外部资源。网页PBR与Max标准材质效果会有差异。

`assets/teapot/pipeline/` 保存可重建配方、真实网格导出与 GLB 转换、独立重新打开检查脚本。原生批处理检查报告和使用说明在 `docs/models/teapot/`。复用调查见管线 README。

上传使用用户原有浏览器空间，个人 R2 作品 ID 为 `5f35ce63-e3b3-4d8c-b167-fa5935983686`。当时线上原件使用含 MAX、贴图和检查文件的 ZIP，模型单独上传 GLB，封面为同一 Max 模型的两角度渲染。本地编辑时从原件目录直接打开 MAX，牡丹贴图随场景保存在同一目录。

上传和修订保持同一作品，保留私密历史；最终实际状态与浏览器验收见 `docs/verification/teapot-20261105.json`。通用MAX云端自动转换仍未接入，这次是本机导出已知茶壶；不能据此宣称任意新MAX自动预览。
