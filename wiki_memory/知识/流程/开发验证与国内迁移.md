# 开发验证与国内迁移

## 开发入口

项目文档要求 Node.js 22.13 或更新版本。从仓库根目录进入网站应用后安装锁定依赖：

```sh
cd formspace
npm ci
npm run dev
```

打开开发服务器实际输出的本机地址，通常为 `http://127.0.0.1:5173/`。本地登录由 Sites 开发插件模拟，仅用于本机开发；当前生产版本使用平台登录身份。

## 验证命令及范围

在同一个 `formspace/` 目录执行：

```sh
npm run typecheck
npm test
npm run build
npm start
```

类型检查验证 TypeScript；`npm test` 运行 `scripts/test-api.mjs` 的内存存储接口测试；构建生成 `dist/client` 和 `dist/server`；`npm start` 用 Wrangler 本地运行已构建 Worker，地址以终端输出为准。`npm start` 不等于部署。

接口测试覆盖匿名及跨站写入拒绝、上传后的列表读取与文件下载、作者权限、格式/数量/大小限制、分页和失败回滚。它不代替真实云存储、实际登录、浏览器三维显示及国内网络验收。记录结果时分别写清本轮执行的检查与旧验收记录，不把命令存在写成已经通过。

`formspace/scripts/import-portfolio.mjs` 是首轮资产导入辅助脚本，读取离线转换资料并核对原件哈希；它依赖工作区资产及 Sharp，不属于日常安装、启动或构建步骤。现有网页资源已在 `public/` 中，重新构建无需重新转换 MAX。

## 国内迁移仍未完成

截至 2026-10-26，源码仍使用 Cloudflare Worker、R2 和 Sites 登录。交付 ZIP 是供继续迁移的原版，不是已完成国内部署的成品。迁移事项来自交接文档：

| 当前平台依赖 | 迁移时需要完成的工作 |
| --- | --- |
| Vite 的 Cloudflare 与 Sites 插件 | 整理目标平台构建和开发代理，保留 React + Vite 前端 |
| Worker `fetch` 与 `env.ASSETS` | 适配目标服务端接口及静态资源服务 |
| R2 的 `put/get/list/delete` | 适配目标持久文件存储和作品记录 |
| `/signin-with-chatgpt` | 替换为目标平台登录入口与会话流程 |
| `oai-authenticated-user-*` | 替换为经过目标服务端验证的用户身份 |

当前身份头只有在可信 Sites 平台注入的边界内才有效。迁移到普通服务器时，不能直接信任浏览器发送的同名 `oai-authenticated-user-*` 请求头；本地模拟用户也不能成为生产身份认证。

仅部署 `dist/client` 会缺少上传、文件接口和作者管理。完整迁移后还需实际验证：首页与模型资源在目标网络可达、登录成功、模型和多图上传、刷新及重启后数据仍在、匿名投稿和他人删除被拒绝、原件下载哈希一致。

初始四件作品随源码交付，远端后来投稿保存在原 R2。交接包没有导出远端后续投稿或用户数据；需要迁移这些数据时，应另行授权导出并核对数量和哈希。
