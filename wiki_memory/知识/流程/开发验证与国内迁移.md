# 开发验证与国内迁移

2026-11-07 当前交接入口为 docs/workbuddy/current/01_先读我.md；完整包使用当前 main 应用快照，不采用 2026-10-25 旧包的品牌/账号合同。Node 入口 server/node-server.mjs 已提供，npm run start:node 使用 dist/client + 源码模块；npm start 仍是 Worker。本轮独立安装、类型、542 项 API、生产构建、9 项 Node 集成和无静态模型副本检查通过。

Node 默认使用 .server-data 的 FS 持久存储，可改 FORMSPACE_DATA_DIR；备份须成对保留 objects/meta。配置 FORMSPACE_COS_BUCKET 后走 COS，四项 COS 环境变量需齐全；真实云 SDK、条件写/分页/Range/失败回滚尚待验证。FS/COS 只按单机单进程使用，不部署 cluster 或多副本共同写入。Nginx/systemd 模板尚未在 Linux 实机执行。

推荐 Node.js 24；Node 22 直接运行 TypeScript 接口测试需 22.18+。在 formspace/ 安装锁定依赖，然后运行 npm run dev；检查命令为 npm run typecheck、npm test、npm run build，npm start 仅运行本机已构建 Worker，不是发布。

本地与生产都使用应用自己的浏览器空间 Cookie，无需模拟账号登录。Vite 保留 sites() 构建集成，但 mockAuth=false；不要恢复旧 /signin-with-chatgpt 流程或信任 oai-authenticated-user-* 请求头。

接口测试维护真实 Set-Cookie jar，覆盖空间隔离、CSRF、过期与续期、坏数据拒绝、版本/公开节点、Range、原件授权、旧数据兼容及回滚。仍需真实 R2 与浏览器验收；本轮 325 项接口、本地 36 项、手机视口 75 项和线上 32 项已通过，范围见交付回执。

第 4 版将 API 扩至 476 项，另有 30 项本地实际浏览器检查，覆盖不限后缀原件、未知扩展名和无后缀、附件/字节保留、MAX 无假预览、补 GLB 新私密版本与跨浏览器隔离。新生产验收见 `docs/verification/source-formats-20261026.json`；上段为第 3 版历史计数。

国内托管迁移尚未完成。需要适配 Worker fetch/env.ASSETS、R2 存储与 HTTPS Cookie，并搬迁 sessions/profiles/records/versions/files 及作者映射。新应用不依赖平台账号，目标环境须保留浏览器凭据的服务端校验、同源写入、私密版本和公开媒体授权。

只托管 dist/client 不能恢复完整服务。换域名时 Host Cookie 不自动跨域；仅复制 R2 不能保证原浏览器管理入口继续有效，需要另行设计授权迁移。旧账号私密数据没有自动绑定新空间，不可凭公开链接认领。

历史 ZIP 是旧版交接快照，新接手以当前源码及 shared/portfolio.ts 为准。远端用户数据不在源码包中；导出迁移需另行授权与数量/哈希核对。MAX 不自动在线转换，既有 public/ 资源构建时无需重导出。
