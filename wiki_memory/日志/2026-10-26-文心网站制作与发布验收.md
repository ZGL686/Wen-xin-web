# 文心网站制作与发布验收

## 目标与确认

用户采纳影视的卡片短预览/详情完整观看方案，并明确结束讨论、授权按已确认规则制作网站。保留原视觉风格、React + Vite 架构，交付可分享网址，继续每轮 Wiki 与 Git 同步。

## 实现

- 品牌变为文心 / 树莓成熟时，保留原四件真实三维作品；新增个人空间与稳定分享链接。
- 四方向加真实标签汇总；全部隐藏标签，换方向清筛选。v1 标签筛选为单选，作品可有多个标签。
- 首次需名称、方向与一份内容，其余选填。每次主动保存自动留一个版本，文字续改可沿用媒体，旧定稿不被覆盖。
- 新作/新版本私密；选定展示版与公开过程节点分开管理，私密新稿不改变访客封面。重要节点、撤回、作者隔离与服务器文件鉴权均接真实 R2。
- 模型卡片可交互；影视卡片默认约 20 秒或作者自选片段，结束可进入详情看全片；HTTPS 交互沙箱运行与演示视频、音频、原图放大均可用。视频与支持的模型尽力自动截封面。
- 主要实现为 App/PortfolioViews/WorkForm/WorkDetail/MediaPreview/media-cover、shared/portfolio、worker/api 与 API 测试。保留原 styles，以 wenxin.css 扩展界面。

## 验证与修复

177 项接口检查、25 项真实 Miniflare R2 集成、桌面及影片流程 27 项、节点/分享/撤回 10 项、390/320 手机检查 64 项、媒体扩展 28 项通过。独立应用目录按锁文件安装、类型检查、接口测试与生产客户端/Worker 构建通过。

浏览器发现并修复了卡片收藏/关闭键遮挡、图片放大/关闭键重叠；放大图通过 Portal 覆盖页面，Escape 关闭后恢复滚动与焦点；卡片影片选段拖动限制在预览范围。过程节点复核等待服务器回执，避免测试脚本误判异步受控勾选框。

线上匿名 15 项检查通过，四份 MAX 的真实下载哈希、四个 GLB 和 WebP 全部核对通过。没有用真实第三方账号执行生产测试上传；作者写入和权限通过相同源码的本地真实 R2 验收。回执为 `docs/verification/wenxin-20261026.json`，公开界面截图保存至 `docs/screenshots/`。

## 发布

复用原 Sites 项目和 public 访问策略，独立应用源码提交 `8c335c9ba3e620961523741ba63cf6db3d7dc135`，保存第 2 版后发布成功：https://formspace-sm-3d-studio.h2969351680.chatgpt.site 。站点显示标题同步为「文心 · 树莓成熟时」。GitHub 工程同步由本轮最终同步脚本完成并核对，不把网站发布与源码推送混为一谈。

## 资产与边界

尊重用户已有的目录改名，将当前原件位置适配为 `assets/3d source/`。四原件哈希不变，新增鼠标 MAX 仅归档为原件，不伪造第五件网页作品。MAX/GLB 等继续使用 LFS。

历史 WorkBuddy ZIP 哈希保持不变，仍是旧版；新版交接以仓库当前源码和合同为准。单次新增文件 40 MiB、单作品 500 版；没有后台自动保存、本机软件监听或一键恢复。国内登录/后端迁移仍未完成，后续迁移需要保留新版权限与索引数据。
