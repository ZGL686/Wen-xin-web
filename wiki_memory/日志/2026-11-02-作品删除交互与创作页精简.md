# 作品删除交互与创作页精简

## 目标和范围

用户选择暂缓通用 MAX 云转换，要求解决上传作品不想保留却难以删除的问题，并减少“记录创作”的文字密度、改善排版。维持长序风格、React/Vite、真实作品、免账号权限与原件，不购买或接入云转换。

## 实现

原删除入口藏在详情底部折叠区，空间卡片没有直接管理按钮。新增共享 DeleteWorkButton，放在自有作品卡片与作者详情顶部；原生 dialog 显示作品名、版本数与全部历史/上传文件永久删除说明。默认聚焦保留，支持取消/Escape；请求中禁重复提交，失败显示错误并保留重试。服务端确认成功后更新列表和收藏，详情返回个人空间。

保留原 DELETE 与 Cookie 授权，系统展品和其他作者作品不增加删除权。原卡片摘要样式会截断确认段落，已用 dialog 限定样式清除截断和高度限制，保证警告完整可读。

创作页默认展示基本信息和作品内容两张卡片；文件/图片/文字/链接分面板且共用草稿状态，介绍/过程/更多设置折叠。右侧为封面、方向、状态、目标版本与私密保存；原件、独立预览、模型文件夹、配套文件、封面重排、演示视频、片段、所有过程字段及保存版本规则保留。

## 验证

- TypeScript、542 项 API、独立应用生产构建与鼠标模型无静态副本检查通过。
- 本地 Edge 34 项实际浏览器检查通过：混合内容上传、原件字节、选填内容、切换保留、续写沿用、跨浏览器读写拒绝、显式入口、取消/安全聚焦、503 重试、永久删除、收藏清理和刷新一致性；包括本地临时公开作品的删除。
- 生产 Edge 30 项真实操作通过，两件本次 QA 始终私密，均精确删除；初末公开作品 ID 集合一致，当前实际公开数为七，不按历史六件数量重置或删除其他投稿。没有编辑或删除原有作品，也不处理旧测试会话。
- 1280×720、1920×1080 和 390×844 没有横向溢出；当前主要交付仍为电脑网页。相同 1440×1000、本机字体条件下，默认可见文字字符 978→305，主区域高度 2728→1293 像素。

回执 `docs/verification/creation-delete-20261102.json`；线上截图 `creation-form-20261102.png`、`delete-dialog-20261102.png`。首次本地检查的继续编辑选择器误用了按钮角色，修正为链接后通过；临时失败记录已按精确 ID 清理。没有以模拟删除代替线上真实删除。
