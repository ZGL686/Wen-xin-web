# 多格式三维查看器集成与发布

## 目标与方案

用户要求在现有网页即点即看模型，无需主动下载原文件或安装软件，提供专业查看器常见的相机操作、常用格式与渲染优化，保持 React/Vite、现有风格和功能。沿用 Three.js，锁定 camera-controls 3.1.2，STEP/STP 采用 occt-import-js 0.0.23 的浏览器 Worker；选型来自相应官方 GitHub 和 Three 文档。按 Sites 技能执行既有站点发布流程，按 ponytail 原则复用现有渲染与权限链路，没有引入另一套查看网站。

## 实施

`ModelViewer.tsx` 提供左键旋转、右键平移、滚轮平滑缩放、双击表面聚焦、居中、自适应、无重复下载的复位、原生全屏/覆盖回退、键盘和触屏手势。手动操作暂停自动旋转。静止、离屏、隐藏时停止重绘，限制 DPR，50 万三角形以上降低像素比并关闭动态阴影。保留环境光、材质、阴影和线框。

`model-loader.ts` 统一 GLB/glTF/OBJ/STL/FBX/STEP/STP、模型包和封面解析。多文件/文件夹入口生成保留相对路径的惰性资源 ZIP；支持中文和空格路径，OBJ 多个 MTL 及纹理按其文件位置解析。未提供的外部地址拒绝请求，ZIP 路径穿越、多主模型、超限解压拒绝；不执行包内代码。Draco、Meshopt、KTX2 接入按需解码，OCCT Worker 可取消/超时并终止。解码文件和 LGPL 许可由锁定依赖在构建时准备到本站。

共享类型、表单、封面、详情和 API 格式/媒体类型同时更新。source 归档、model 预览仍为分角色、分权限的版本资源。一般 source ZIP 不自动认成模型，只处理明确提供的 previewModel ZIP。MAX 原件与原四作验证基线未改写。
