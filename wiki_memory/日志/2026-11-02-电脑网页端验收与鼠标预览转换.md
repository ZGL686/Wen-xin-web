# 电脑网页端验收与鼠标预览转换

## 目标与确认

用户明确以电脑浏览器网页端为当前交付目标，并追加要求转换已有鼠标的网页预览。保留长序风格、React/Vite/TypeScript、免账号空间、真实作品及原件，不扩展为手机 App 或通用 MAX 云转换服务。

## 变更

- 首页手动旋转同步暂停按钮状态，复位以 resetToken 调整相机，保留同一 Canvas 且不重新请求 GLB；提示明确左键旋转、右键平移与滚轮缩放。
- 已有 ARC01 鼠标 MAX 与线上原件 SHA-256 完全一致。使用用户指定的 3ds Max 2026 只读导出真实求值几何，82 个网格、131,144 个三角形、9 种网页材质。GLB 为 3,464,316 字节，原件不改写；未使用 Blender 重建。
- 衍生模型读取时关联原 R2 作品的两个已核实源版本；保留作者、封面、名称、原件、公开指针和不可变历史。后续正常保存可以沿用预览，明确清除或换原件仍按原规则处理。
- API 在检查作者/公开节点后读取模型，保持 HEAD、Range、If-Range、private/no-store 和 Vary: Cookie。模型仅内联在服务端 Worker，不进入 public 或客户端包。

## 验证与发布

542 项 API、TypeScript、独立生产构建及服务端模型无静态副本检查通过。电脑 Microsoft Edge 156.0.4314.58 的 27 项最终线上检查通过，覆盖鼠标/键盘、复位不重下载、卡片全屏及 1280×720、1366×768、1920×1080 的首页/展厅/详情/上传布局。鼠标另外 16 项线上检查通过，包括真实 WebGL 交互、模型 SHA-256、HEAD、206 Range、无原始静态模型和无浏览器下载；附加核对原封面和两个公开历史节点保持不变。

公开作品仍为六件，包含原四作、键盘和已有鼠标。生产测试无作品/历史写入，不创建、公开或删除 QA 投稿，不据公开数量推断私密数据。原件、下载副本、网页基线和历史交付包完整性检查通过。

Sites 第 8 版发布成功，网址 https://formspace-sm-3d-studio.h2969351680.chatgpt.site 保持 public。源码 `67faab52867350a39d441211ddf37c6392d6c184`；保存版本 `appgprj_6addc2985e6c8191b7e6b6a746e0911c~appgver_653313bbc22c8191bf85ee28858bdea4`；部署 `appgdep_6ae80b8d7b9c8191b66da918ccee2127` 为 succeeded。回执 `docs/verification/desktop-mouse-20261102.json` 和 `mouse-conversion-20261102.json`，截图保存在同目录。

## 发现并处理的问题

首页复位重新请求模型和手动控制按钮不同步已由桌面检查复现并修复。初次第 7 版线上检查发现托管优先直出静态文件，本地 run_worker_first 与路径保护不能阻止实际静态读取；第 8 版将 GLB 移到仅服务端的 data/models，构建及生产均验证没有可绕过鉴权的静态副本。该鼠标原件本来已有公开下载；本次没有公开其他作品或修改作者记录。

## 遗留与长期事实

通用 MAX 云转换、国内迁移、跨浏览器/实体 GPU 性能矩阵和超大装配压力测试仍未完成。手机真机矩阵为可选兼容检查，不作为当前电脑网页端交付阻塞。网页 PBR 为原材质的近似转换，不承诺专业渲染器效果完全一致。
