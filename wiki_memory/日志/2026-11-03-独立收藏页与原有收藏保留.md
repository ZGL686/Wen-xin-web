# 独立收藏页与原有收藏保留

## 问题与实现

用户指出收藏后没有单独的展示界面。核实旧页面只有当前作品列表内的收藏筛选，缺少独立路由及主导航入口。已新增 `/#/favorites`，在主导航和作品列表工具栏中提供“我的收藏”，保留原视觉、架构和 localStorage 收藏键。

收藏页集中读取已收藏 ID 当前可访问的作品，包含当前作者的私密创作；复用原卡片和预览，提供搜索、方向、标签、排序和取消收藏。无收藏时引导去展厅，取消后立即移除，同浏览器其他标签页同步爱心和数量。旧重复/无效条目安全过滤，不清空已有收藏。

读取经过原服务端权限接口，四请求并行、离页取消、按 owner 隔离结果。403/404 提示暂不可查看并保留引用；临时加载失败区分显示并重试，部分成功不丢失。未新增账号、跨设备同步、后端接口、权限或依赖，未购买云转换，也未改写原作品和原件。

## 验证

- 类型检查、独立应用生产构建、鼠标受保护资源无静态副本检查通过。
- 本地 Edge 31 项通过；创建一件私密测试作品验证作者可看与其他浏览器不可看，按精确 ID 删除。
- 生产 Edge 29 项通过；作品只读，无线上创建/编辑/删除，初末公开作品 ID 集合一致，公开数七。
- 流程覆盖从展厅收藏、专页、详情取消、刷新、旧记录、两标签页双向更新、去重标签与重置、排序、部分和全部失败重试、不暴露不可见元信息以及坏 JSON。
- 1280×720、1920×1080、850×900、390×844 无横向溢出，无浏览器运行异常。后两者为窗口布局检查，不是手机实体测试。

首次本地脚本直接更改 localStorage 后用同 URL 导航，未触发重新初始化；改为显式刷新后全部通过。修正的是测试等待方式，未以伪造后端响应替代正常收藏读取；故障案例才使用明确客户端夹具。

本轮 API 未修改，未重跑整套 542 项历史接口检查。回执 `docs/verification/favorites-20261103.json`，已检查线上截图 `docs/verification/favorites-20261103.png`。
