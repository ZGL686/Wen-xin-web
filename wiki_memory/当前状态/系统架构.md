# 系统架构

## Node 本地适配与国内交接（2026-11-07）

当前源码已包含 server/node-server.mjs，复用 worker/api.ts 与共享类型，提供同源 API 及 dist/client 静态服务；默认回环 8788，数据采用 .server-data 的 FS 适配，可由环境变量选择尚未真实云端验收的 COS 适配。npm run start:node/test:node 已存在，不将 Node 后端写成待开发。原生产仍为 Worker/R2，构建链继续保留 Cloudflare/Sites。FS/COS 条件写入依赖进程内锁，只按单进程测试候选，不作为跨实例原子存储。HTTPS 反向代理须保持 Host、覆盖 X-Forwarded-Proto 并通过同机回环连接；换域名不会自动迁移 Cookie 或收藏。完整交接见 docs/workbuddy/current/ 与本轮回执。

以下为现有网页及原 Worker 架构。

2026-11-07 新增的 Node 目标已在本机独立副本验证：server/node-server.mjs 复用 worker/api.ts，提供静态文件和 API，使用 r2-fs-bucket.mjs 或待真实验证的 r2-cos-bucket.mjs。start:node 启动 Node 入口，原 npm start 仍为本机 Worker。FS/COS 按单机单进程使用，HTTPS 由同机反代保留 Host 和覆盖 X-Forwarded-Proto；不代表现站或国内托管已切换。交接和边界见 [[知识/流程/开发验证与国内迁移]]、docs/workbuddy/current/。

第 10 版新增 `src/Favorites.tsx` 和 `/#/favorites`，主导航及 Collection 工具栏链接至独立收藏页。继续使用原 localStorage ID 列表；App 监听 storage 事件同步标签页，safeFavorites 去重和忽略无效值。页面最多四请求并行读取原鉴权详情接口，按当前 owner 隔离结果，保留不可访问引用并区分网络故障。复用 Collection 的搜索、方向/标签、排序及 WorkGrid，未变更 Worker/R2/API/依赖。详见 [[知识/模块/独立收藏页]]。

第 9 版对作品管理和创作页进行界面改版，API 合同和存储结构不变。`DeleteWorkButton.tsx` 共用于自有作品卡片与作者详情，使用原生 dialog 和现有 DELETE 接口；`App.tsx` 在确认成功后同步公开列表和收藏，`CreatorSpace` 同步个人列表。`WorkForm.tsx` 保留所有提交/权限/版本逻辑，使用内容分面板、折叠选填区和右侧私密保存摘要；布局样式位于 `work-form.css`。详见 [[知识/模块/创作表单与作品删除]]。

第 8 版已完成电脑端首页复位/旋转状态修复，并给已有鼠标补充真实 MAX 衍生预览。`data/derived-previews.ts` 只匹配已验证的作品、版本和源文件；只读投影补充 modelUrl，不改写不可变历史。`worker/derived-model.ts` 将小型已验证 GLB 仅内联到服务端，文件接口校验作者/公开节点后按需解码，沿用 GET/HEAD/Range/If-Range 和 private/no-store。用户后续保存可继承、清除或随新原件替换预览。详见 [[知识/模块/鼠标模型与网页预览]]。

不能把私密或可撤回的衍生文件放到 public 后仅靠 Worker 拦截；当前托管会优先提供已存在的静态资源。发布前 `scripts/test-derived-build.mjs` 检查客户端产物无鼠标模型字节或 base64 副本。原件、R2 作品记录与权限合同不因补充模型改变。

2026-11-02 第 6 版已发布多格式在线查看器。相机、加载和资源边界见 [[决策/ADR-008-浏览器多格式三维预览]]、[[知识/模块/浏览器三维查看器]]，发布回执为 `docs/verification/model-viewer-20261102.json`。

当前品牌为「长序」，空间无需账号登录。作者权限由服务端验证当前浏览器的高熵 Cookie，免账号不等于取消私密数据的权限隔离。第 4 版已发布不限格式原件归档及真实预览状态提示，第 5 版加入原生 Max 参考键盘及其预先导出的真实预览。当前五件系统展品保留原四件验证基线，已有用户 R2 投稿独立保留；云端原生转换尚未配置。键盘管线见 [[知识/模块/键盘模型与网站预览]]。

前端为 React 19.2.6、Vite 8.0.13、TypeScript 5.9.3。`formspace/src/App.tsx` 负责 hash 路由，页面已分到 `PortfolioViews.tsx`、`WorkForm.tsx`、`WorkDetail.tsx`；`ModelViewer.tsx` 结合 camera-controls 平滑控制相机，`model-loader.ts` 加载 GLB/glTF/OBJ/STL/FBX/STEP/STP 和含配套资源的预览 ZIP，`MediaPreview.tsx` 提供按内容展示模型、图片、音视频或 HTTPS 体验的预览入口。共享 API 类型位于 `formspace/shared/portfolio.ts`。

页面包括首页、公开作品库、我的收藏、我的空间、个人分享空间、新建/编辑、作品详情与关于。个人空间使用稳定 slug；公开资料与公开作品可分享，私密作品及完整历史仅当前作者读取。主方向为交互、影视、三维、其他，自填标签独立保存。

`worker/index.ts` 将 `/api/*` 交给 `worker/api.ts`，其他请求交给静态资源绑定。当前仍运行 Cloudflare Worker/R2，未使用 D1；应用已不依赖 Sites/ChatGPT 账号身份，国内托管和持久存储迁移尚未完成。

| 接口 | 当前合同 |
| --- | --- |
| `POST /api/session` | 同源创建或幂等复用浏览器空间，通过 HttpOnly Cookie 保存凭据 |
| `GET /api/me` | 只读现有空间；缺失、无效或明确过期凭据返回空身份，不创建或续期 |
| `PATCH /api/me/profile` | 有效空间修改名称和简介 |
| `GET /api/profiles/:slug` | 个人资料及该空间的公开展示作品 |
| `GET /api/works?scope=public` | 公开展示版本；可按 `profile=slug` 限定空间 |
| `GET /api/works?scope=mine` | 当前作者的最新快照，含私密作品 |
| `GET /api/works/:id` | 作者完整历史或访客选定公开节点；可用 `version=id` 回看允许的版本 |
| `POST /api/works` | 私密新作；名称、方向和至少一份内容必填 |
| `PUT/PATCH /api/works/:id` | 同作品新增版本，校验 `baseRevision`，可沿用已有媒体 |
| `PATCH /api/works/:id/publication` | 校验 `revision`，选择展示版、公开过程节点、重要节点或撤回展示 |
| `GET/HEAD /api/files/...` | 按作者或公开节点逐次鉴权，媒体支持 Range/206/416 |
| `DELETE /api/works/:id` | 作者删除整件作品及其版本文件；系统展品不可修改或认领 |

R2 使用 `sessions/` 保存令牌哈希、随机空间 owner 与有效期，`profiles/` 保存资料、`records/` 保存作品索引、`versions/` 保存不可变快照、`files/` 保存附件。文件按作品、版本和 source/model/image/video/audio 等角色组织。先保存资源与快照，再通过条件写入提交作品指针；竞争更新返回 409，失败会回滚本次未提交资源，对提交结果不明确的回执先读回确认，避免删除已提交内容。

生产 HTTPS 使用 `__Host-changxu_workspace`，具备 Secure、HttpOnly、SameSite=Lax、Path=/ 且无 Domain；只有回环 HTTP 开发使用 `changxu_workspace`。256 位随机令牌只存在于浏览器 Cookie 和本次请求内存中，R2 仅保存 SHA-256，不在 JSON 返回。所有写入均检查 Origin，忽略客户端伪造的 `oai-authenticated-user-*` 和旧模拟登录 Cookie。

页面初始化以单次进行中的请求及跨标签页 Web Lock 协调幂等 POST，再由 GET 确认 Cookie 生效。POST 复用相同令牌和 owner；剩余不足 30 天时延长到 365 天，GET 永不续期。清除 Cookie、长期到期、换浏览器或设备不能自动恢复旧空间；原数据不会因此被删除或自动交给新空间，本轮没有恢复码系统。

凭据对象存在但 JSON/结构/owner/hash 损坏时返回 503，不覆盖仍可能恢复的 Cookie。作品只有明确 v1 形状才走旧公开兼容；未知 schema、混合私密索引或坏 schema 2 指针返回 503，不推断成公开。接口 JSON 与文件 API 响应均使用 `private, no-store` 与 `Vary: Cookie`。

新作默认私密，新保存不替换访客看到的展示版本。仅公开展示版不自动公开该版过程说明；过程、困难、解决和心得仅随作者明确选择的公开历史节点返回。新资源的原件 source 与网页模型 model 分角色，原件默认不允许访客下载；公开预览字节仍会传给浏览器，不能承诺模型防下载。文件响应为 `private, no-store`，撤回后的读取重新鉴权。旧版已公开记录保持原展示和下载行为，内置四件属于系统展品。

旧账号 owner 的资料、作品与私密历史保留，不靠身份头或新浏览器自动认领/迁移。schema 2 仍严格遵守原展示与公开节点指针；v1 原公开上传保持兼容。公开列表只能验证公开范围，不能证明远端私密数据为空。

当前实现限每件作品 500 个保存版本、每次新增文件合计 40 MiB、图片单张 12 MiB、最多八张、JSON 请求 128 KiB。状态为创作中/定稿，和公开范围独立。主动保存即使没有变化也留版；没有后台自动保存或本机文件同步。收藏仍为浏览器 `localStorage` 偏好。

source 不限制后缀或是否有后缀，原名和字节保留，未知后缀对象为 source.bin。原件 GET/HEAD/Range 强制附件及 application/octet-stream/nosniff；独立 model 支持 GLB/glTF/OBJ/STL/FBX/STEP/STP 及明确选择的模型资源 ZIP。STEP 在浏览器专用 Worker 网格化，不是服务端 MAX 转换。前端只按真实资源显示预览，无资源不伪造转换状态。用户选择独立云端且暂无资源，APS 优先验证与 Windows 替代均见 proposed 方案 `docs/cloud-conversion-plan.md`，未部署任务服务。

2026-10-26 本轮验证：325 项 API 检查及全量 TypeScript 检查通过；36 项本地真实浏览器/R2 检查通过，回执为 `formspace/outputs/qa-changxu-local.json`。覆盖直接文件上传、刷新同空间、跨标签页、不同浏览器读写隔离、公开/私密版本、Cookie 丢失后旧稿仍保留及精确删除。之前 177 项接口和 25 项真实 R2 检查属于文心账号版历史验收，不作为当前免账号权限的替代证明。

本地在 `formspace/` 安装与运行，构建输出 `dist/client`、`dist/server`；后者仍为 Worker。未来迁移须保留服务端验证的 Cookie 和持久数据，不能用身份头或只复制前端替代。GitHub 同步与站点发布分开执行。
