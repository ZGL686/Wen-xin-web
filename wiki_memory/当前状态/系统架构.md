# 系统架构

前端是 React 19.2.6、Vite 8.0.13、TypeScript 5.9.3，Three.js 动态加载。`formspace/src/App.tsx` 提供首页、作品库、详情、上传、关于页及 hash 路由；`src/ModelViewer.tsx` 负责真实 GLB/OBJ/STL 预览。

`worker/index.ts` 将 `/api/*` 交给 `worker/api.ts`，其他请求交给静态资产。当前服务器运行于 Cloudflare Worker，R2 `BUCKET` 保存新增作品记录与文件，D1 未使用。

| 接口 | 边界 |
| --- | --- |
| `GET /api/works` | 公开作品列表与当前用户；初始条目来自 `data/works.json` |
| `POST /api/works` | 登录、同源校验、multipart 上传和失败回滚 |
| `GET/HEAD /api/files/:uuid/:file` | 图片、模型与原件读取 |
| `DELETE /api/works/:uuid` | 仅作者可删除新增作品，内置作品不可删除 |

R2 的 `records/{uuid}.json` 保存元数据，`files/{uuid}/source.ext` 与 `image-N.ext` 保存文件。收藏保存在当前浏览器 `localStorage`，作品不存浏览器。

原版身份由 Sites 注入，前端登录入口为 `/signin-with-chatgpt`。在通用服务器迁移时必须换成服务端验证的会话，不能信任浏览器传来的同名身份头。

本地在 `formspace/` 执行 `npm ci`、`npm run dev`。生产构建输出 `dist/client` 和 `dist/server`；后者仍为 Worker，不能直接当作 Node 常驻服务。
