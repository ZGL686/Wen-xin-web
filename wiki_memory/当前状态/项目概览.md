# 项目概览

项目仓库为 `ZGL686/Wen-xin-web`，网站名称为「形间 FORM / SPACE」。目标是保留真实三维作品与交互展厅，并继续迁移到适合中国用户的部署环境。

当前已实现 React + Vite 展厅、五类页面、模型/图片上传、下载和作者删除。初始作品为房子、柜子、AURELIA 玉石灯、Cloud Bear 云朵熊沙发。国内后端和登录迁移尚未完成。
