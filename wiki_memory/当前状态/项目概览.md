# 项目概览

项目仓库为 `ZGL686/Wen-xin-web`。已确认的产品目标名称为「文心」，副标题「树莓成熟时」，以高校数媒学生为首要人群，每位创作者拥有独立作品集，兼顾公开展示与私密归档。当前实际源码和原站仍为「形间 FORM / SPACE」，上述新定位尚未实施。

当前处于产品讨论阶段，用户要求先讨论、不制作。分类草图已确认第一层为全部/交互/影视/三维/其他，第二层为所选方向下作者自填标签；详见 [[决策/ADR-003-文心定位与两级作品分类]]。

新增核心目标是记录作品从灵感初稿、困难解决、修改上传到定稿的过程，允许持续修改并保留历史，也容纳长期未完成的作品。过程默认私密，由作者选择公开节点；详见 [[决策/ADR-004-创作过程与私密版本历史]]。这些是已确认需求，尚未实现。

低负担保存规则已确认：首次需要作品名称、主方向、至少一份内容，其余作品表单补充信息选填；主动保存/重新上传自动留版本，定稿后可以继续修改并保留旧定稿。后续补文字可沿用已有文件。这些仍为待实现产品要求。

封面目标为直接展示作品并提供预览：三维有动效与交互，影视封面带播放键在卡片内观看，可网页运行的交互作品直接体验，其余用演示视频展示。封面继续选填；详见 [[决策/ADR-005-作品封面与多媒体预览]]。

当前已实现 React + Vite 展厅、五类页面、模型/图片上传、下载和作者删除。初始作品为房子、柜子、AURELIA 玉石灯、Cloud Bear 云朵熊沙发。国内后端和登录迁移尚未完成。
