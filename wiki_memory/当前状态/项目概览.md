# 项目概览

项目仓库为 `ZGL686/Wen-xin-web`。网站现名「文心」，副标题「树莓成熟时」，含义为“为文之用心”。面向数字媒体创作者，首要人群为高校数媒学生；每位作者拥有独立作品集与分享链接，兼顾私密归档和公开展示。用户于 2026-10-26 明确结束讨论并授权制作。

本轮已实现并发布 Sites 第 2 版，公开地址为 https://formspace-sm-3d-studio.h2969351680.chatgpt.site 。2026-10-26 已实际验证线上品牌、四件真实作品、三维渲染、分类标签、个人展示入口、手机导航和四份 MAX 下载哈希。线上沿用原网址与公开访问策略；国内托管及登录迁移仍未完成。GitHub 源码同步与网站发布依然是两项操作。

## 当前能力

- 保持 React + Vite + TypeScript 和原有浅色、墨黑、荧光绿的编辑感视觉，以及房子、柜子、AURELIA 玉石灯、Cloud Bear 云朵熊沙发四件真实作品。
- 主方向固定为交互、影视、三维、其他；全部为浏览筛选。每件作品一个方向、多标签，二级标签从当前方向作品去重汇总；全部时隐藏，换方向清除旧标签。
- 个人空间含私密作品、完整历史、个人介绍编辑和公开作品集分享。初始四件是系统展品，不开放给任意账号认领。
- 首次保存需要名称、方向和至少一份内容，其余选填。主动保存自动留下版本，文字修改可沿用媒体，旧定稿继续保留。过程、困难、解决与心得可选填。
- 每个新作品和新版本先私密保存。作者分别选择公开展示版本、公开过程节点和重要标记；新草稿不替换旧公开封面或媒体。撤回后文件重新鉴权。
- 三维卡片可激活旋转缩放；影视卡片预览片段、详情播放全片；可网页运行的交互通过 HTTPS 体验，其他可配演示视频；支持图片和音频预览。一次一个卡片活跃，声音由访客决定。
- 封面选填，作者图片优先；可处理的 GLB/OBJ/STL 或视频尽力自动取画面，失败仍能保存。MAX/BLEND 等原件不会自动转换为网页模型。

## 技术与验收

现后端为 Cloudflare Worker/R2，线上仍使用 Sites/ChatGPT 身份。本次接口的 177 项检查、25 项真实 Miniflare R2 集成检查、桌面作品与影视流程、10 项节点/分享/撤回检查、64 项手机尺寸检查、28 项扩展媒体检查均通过。线上以匿名访客进行 15 项验收；登录后的新建、编辑与权限流程在相同源码的本地真实 R2 环境验证，没有冒称完成第三方真实账号的线上登录验收。

生产源码提交为 `8c335c9ba3e620961523741ba63cf6db3d7dc135`；回执及验收边界见 `docs/verification/wenxin-20261026.json`。目前每次新增文件合计 40 MiB，每件作品最多 500 个保存版本；无后台自动保存、本机软件同步或一键历史恢复。
