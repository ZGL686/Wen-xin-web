# 当前待办

## 当前优先讨论

用户因当前名称已被使用，要求仅讨论网站新名称，偏好简短好记的 2—3 字中文品牌名，并要求气质更大气、更高级。先比较名字的语感、记录创作过程的含义与媒体覆盖范围，再对收敛候选做重名和可用性核查；未选定名字，不改网页或发布。候选为助手提议，不能记为用户已确认。本轮进一步比较「成象」「长序」「成叙」等气质；此前候选并未被用户明确全部否决，新名称仍待选择。核心产品定位和功能规则继续保留。

## 此前实现与发布

用户已明确从产品讨论转入制作。本轮文心品牌、原风格保留、两级分类、个人空间、低负担保存、私密版本历史、公开节点与展示版选择、多媒体卡片/详情预览均已实现；原有四件真实作品保留，Sites 第 2 版已发布到原分享网址。

本地类型、177 项接口、25 项真实 R2、桌面影视与作品流程、节点与分享、390/320 尺寸及扩展媒体检查已完成。线上匿名验收与四份 MAX 哈希核对已完成，回执见 `docs/verification/wenxin-20261026.json`。本轮摘要、工程记忆、源码与资产路径将按持续授权由同步工具提交推送；最终 Git 结果以脚本和 HEAD 核对为准。

## 独立的后续工作

1. 国内托管、登录和存储迁移仍待完成。迁移必须保留新版本、展示指针、公开过程白名单、文件角色授权及作者隔离，不能只复制前端或沿用旧版只新建/删除的接口合同。
2. 历史 WorkBuddy ZIP 为 2026-10-25 的旧版快照，不含本轮文心功能；当前接手以 `formspace/README.md` 与 `formspace/shared/portfolio.ts` 为准。若要交付新版 ZIP，需从当前源码重新打包并单独验收。
3. 如迁移线上后来投稿，应另行导出 R2 的 profiles/records/versions/files，并建立目标用户映射；源码备份不等于远端作品数据备份。
4. 需要更大影视文件时，可另行规划分片直传；当前单次新增文件合计 40 MiB。历史一键恢复、后台自动保存和更多浏览器/真实手机设备验收尚未实施，不能把它们算入本轮交付。
