# 当前约束

- 保留 React + Vite + TypeScript，保留当前页面、内容、视觉风格、交互和手机适配。
- 保留四个真实作品；MAX 原件不可改写；网页 GLB 使用真实几何，基础材质为近似。
- 上传必须服务端持久化并验证身份；不能用本地存储或假成功替代。公开浏览、作者管理自己的新增作品。
- 每次项目对话或修改结束后写摘要、更新受影响记忆并提交推送到 `https://github.com/ZGL686/Wen-xin-web.git` 的 `main`。这是用户明确的持续授权。
- 新需求和未经验证的推断标为 proposed；已经确认的要求与经源码/测试核实的事实可自动维护 active 页面。
- 只记录工程结论，不上传完整聊天、私密信息、凭据、缓存、运行数据库和 `.local-history/`。
- 二进制 MAX/BLEND/FBX/GLB/ZIP 使用 Git LFS；需要校验实际文件，不能把指针当模型。
- 国内迁移尚未完成；GitHub 源码同步与站点发布是两项独立工作。
- 不强推、不自动 reset/clean、不覆盖他人远端提交。遇到权限或网络阻塞保留本地结果并报告。
