# 当前约束

- 用户已确认长序为新品牌并恢复制作，要求移除账号登录，采用当前浏览器自动识别的免账号个人空间。此前仅讨论命名的限制已撤除，不能再把长序记为未采纳候选。
- 品牌为长序/CHANGXU，副题树莓成熟时，核心句为每一份创作留下来路。保留原风格、React + Vite + TypeScript、四个真实作品及其交互，不改写原始文件。
- 浏览器凭据决定作者权限，作品仍存服务端；免账号不等于全站共享编辑权限。不同浏览器独立，新作品及新版本默认私密，公开展示版和公开过程节点分开选择。
- 当前应用不依赖 Sites/ChatGPT 登录或客户端身份头，不重新加入注册、登录、退出、账号头像或恢复码登录流程。
- HTTPS 使用 Secure/HttpOnly 的 __Host- Cookie；凭据不能进入公开 URL、前端 JSON、localStorage、日志或仓库。GET/me 只读，初始化及写入同源校验，坏凭据和未知记录格式拒绝访问。
- 清除站点 Cookie、换浏览器/设备或凭据到期不能自动找回旧空间；网页须准确说明这一限制，不能说作品文件存本地。身份变化时保留未保存输入，不把旧作品自动转存新空间。
- 旧账号数据原样保留，公开行为兼容；旧私密历史不自动迁移、公开或被新浏览器认领。不得从公开作品数量推断私密数据为空。
- 四方向、作者标签、首次名称+方向+内容必填、每次主动保存留版、旧定稿保留、预览与原件独立授权等既定规则继续有效。
- MAX 原件位于 assets/3d source/，四作哈希以 verification.json 为准；新增鼠标原件不算已制作网页作品。二进制继续使用 LFS。
- Cloudflare Worker/R2 托管尚未迁移到国内。GitHub 推送与网站发布分别验证；换域名时浏览器凭据不能自然跨域，迁移需另行设计和验收。
- 每轮按用户持续授权更新脱敏摘要与受影响 Wiki，提交普通推送。不开后台聊天监听，不上传凭据、环境值、缓存、运行数据或完整聊天，不强推/reset/clean。
