# 当前约束

- 当前阶段再次转为仅讨论：用户反馈「文心」已有他人使用，要求先讨论网站新名称，暂不制作。新名称未定且未明确恢复制作前，不改页面、品牌资源、API 或发布网站；工程 Wiki 摘要同步仍按持续授权执行。
- 线上仍使用文心，副标题树莓成熟时；新品牌待确认。已确认命名偏好为简短好记的 2—3 字中文名，助手候选不视为采纳。保留现有奶油白、墨黑、荧光绿风格和 React + Vite + TypeScript 架构，持续兼顾桌面与触屏。
- 四个方向固定为交互、影视、三维、其他；全部仅筛选。每作一个方向、多标签，第二排汇总去重、换方向清筛选、全部隐藏二级标签。当前二级标签单选为实现选择。
- 新作与每次新保存版本先私密。完整历史仅作者可见，由作者选择展示版和公开历史节点；新私密稿不自动替换访客画面，定稿后继续修改也保留旧快照。
- 只要求名称、方向与至少一份内容；标签、封面和过程说明等选填。每次主动保存留版；不代表监听本机文件或保存未上传的软件编辑。
- 新 source 原件默认不允许访客下载，与 model 网页预览分角色。公开预览字节可被浏览器取得，不能承诺防下载；旧公开记录保持兼容。GET/HEAD/Range 同样鉴权。
- 保留四件系统展品和真实原件；系统展品不能由首位登录用户认领。MAX 原件在 `assets/3d source/` 不可改写，四作哈希以 `formspace/public/portfolio/verification.json` 为准；网页 GLB 为真实几何、基础材质近似。
- 新增鼠标 MAX 作为项目资产保留，尚未进入四作网页基线；不能把原件存在称为已经制作网页预览。
- 上传和版本必须在服务端持久化并验证身份，不能用浏览器本地存储或假成功替代。个人分享页只暴露公开作品，作者空间及完整历史依赖当前登录身份。
- 当前仍使用 Cloudflare Worker/R2 与 Sites 登录。国内托管、国内登录与后端迁移是后续工作，不能把前端复制或本次发布称为国内迁移完成。
- GitHub 同步与站点发布分开执行。当前第 2 版已取得成功回执并完成线上匿名验收；后续修改仍须重新发布才能上线。
- 每轮项目对话或修改结束后，按用户持续授权更新摘要与受影响 Wiki，提交并推送到 `https://github.com/ZGL686/Wen-xin-web.git` 的 main，不重复询问。
- 已确认要求与源码/测试核实事实可维护为 active；新增推测或未确认提案保持 proposed。只保存工程结论，不上传完整聊天、私密资料、凭据、环境值、缓存、运行数据库和 `.local-history/`。
- MAX/BLEND/FBX/GLB/ZIP 使用 Git LFS；交付核验真实文件，不把指针当有效作品。不强推、不 reset/clean、不覆盖他人提交，阻塞时保留本地并说明。
