# ADR-002：每轮记忆与版本同步

用户于 2026-10-26 要求每次本项目修改或对话后自动更新工程记忆、提交并推送到指定 GitHub 仓库。这是当前项目持续有效的授权；不为相同同步动作重复询问。

每轮先更新受影响的当前事实、知识和决策，再使用 `tools/project-sync.ps1` 记录摘要日志、刷新索引、检查资料，提交并普通推送 `origin main`。纯讨论也追加 `discussion` 日志；每篇日志独立、封存后不改写。

当前事实以源码、资料、测试和确认的用户要求为依据。未经确认的推断留在 proposed；不复制完整聊天、私密数据、凭据或内部推理。

同步工具校验仓库根、分支和目标 URL；检查敏感路径、普通大文件与 LFS；远端较新或 push 失败时停止并保留本地提交，不强推或自动重置。程序不监听其他软件的聊天，由读取根 `AGENTS.md` 的 Agent 每轮调用。

日志不写入自身提交 SHA 以避免自引用；同步成功由 Git 回执与本地/远端分支一致来确认。源码同步不等于发布网站。
