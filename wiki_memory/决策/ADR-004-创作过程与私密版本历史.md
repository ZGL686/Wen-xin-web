# ADR-004：创作过程与私密版本历史

这是已确认的产品目标，尚未实施。本阶段仍为项目经理视角的产品讨论，不修改网站或制作视觉资产。

## 已确认的理念与能力目标

文心是数字媒体人的专属作品集。作品从灵感与初稿开始被记录，容纳困难与解决办法、修改上传的痕迹和定稿。作者可以回来继续修改，更改历史应被保留。

「树莓成熟时」表达整个被记录的成长过程，而不是只把交作业或定稿当作成熟；未完成也是诚实的创作状态，允许作品长期停留在未完成阶段。

## 已确认的可见性原则

完整的初稿、修改、困难及解决记录默认私密，只有作者可见。作者选择哪些节点公开给访客，公开作品不自动公开其全部历史。作者完整历史与访客看到的创作历程是不同视图。

## 待确认的产品细节

- 什么算一次版本：站内主动保存、上传文件、阶段性保存或自动保存。
- 定稿后再次修改的呈现方式，以及历史定稿如何回看。
- 公开节点的更新与撤回、版本回看或恢复的具体规则。
- 如何把作品完成程度与公开范围独立表达，状态名称尚未确定。

「每次更改保留」不能在实现前被夸大为记录用户电脑软件里所有未上传操作。当前网站没有文件系统同步能力，版本边界需要明确。

## 当前实现边界

现有 API 只支持作品新建和作者删除；尚未实现作品编辑、版本历史、过程记录或节点级私密/公开控制。后续获准实施后，需把这些能力连同权限边界一起设计验证。
