# ADR-004：创作过程与私密版本历史

用户已明确恢复制作，并采纳长序品牌与免账号浏览器空间。以下区分已确认的产品原则和实现选择；本轮接口和真实浏览器本地验收完成，生产发布仍以交付回执为准。

## 已确认的产品原则

长序是数字媒体人的专属作品集，原项目曾使用文心品牌。作品从灵感、初稿到修改、困难与解决、定稿都值得被记录。「树莓成熟时」表达被记录的成长过程；未完成是诚实的创作状态，不要求先定稿才保存。

- 完整创作过程默认私密，只有作者可见。作者选择哪些节点公开，公开作品不自动公开全部历史。
- 定稿后继续修改仍是同一作品，旧定稿保留为历史节点。
- 每次主动保存或重新上传保留一个版本，可标记重要节点，不要求额外“另存为”。
- 修改说明、困难、解决和心得选填；首次名称、一个主方向和至少一份内容必填，其余作品补充信息选填。
- 后续可沿用已有文件，补充文字不必重新上传。

## 当前实现

当前作者由浏览器空间 Cookie 证明，不再要求账号登录。`POST /api/session` 同源创建或复用空间；`GET /api/me` 只读，不暗中创建或续期。前端自动准备并验证 Cookie，在同浏览器标签页间协调，写入时若空间 owner 已变化不会把旧稿当作新空间作品自动提交。

`POST /api/works` 创建私密作品；`PUT/PATCH /api/works/:id` 带 `baseRevision` 在同作品内增加快照。`GET /api/works?scope=mine` 返回作者最新稿，详情向作者返回完整历史。定稿状态保存在每次快照中，后来编辑不会改写旧快照。

作者通过 publication 接口独立选择 `displayVersionId`、`publicVersionIds`、`importantVersionIds`。新私密稿不替换访客所见的展示版。仅选择展示版只公开作品内容与预览；该版过程、困难、解决和心得仍不返回访客，除非作者明确将它加入公开历史节点。撤回展示会隐藏整作及文件，保留作者完整历史。

访客只取得展示版及明确公开的节点，不得获得私密版本 ID、真实历史总数、最新私密指针或对应资源。新资源 source 原件与 model 网页预览分角色保存；原件下载另由版本开关控制。媒体 Range/HEAD 同样鉴权，文件使用 `private, no-store`。公开模型预览必须向浏览器传递模型字节，不承诺防下载。

R2 先保存附件与版本，再以条件写提交作品索引；竞争更新返回 409，不覆盖其他窗口。失败回滚未提交资源，对不明确的提交回执先读回确认，避免破坏已经提交的版本。明确 v1 公开记录保留原公开/下载行为，schema 2 仍服从原展示指针；四个系统展品不能被浏览器空间认领。

旧账号资料和私密历史保留，不从客户端身份头或第一个新浏览器自动绑定。不把公开作品数量当作私密数据为空的证据，也没有宣称旧私人历史已迁移到免账号空间。

## 本次实现选择与边界

以下是制作时采用的具体边界，不伪装为用户曾逐项指定：

- 无实际变化但主动保存也新增版本；不提供后台自动保存，不记录电脑中未上传的操作。
- 状态采用创作中 `in-progress` 与定稿 `final`；公开范围单独表达。每作最多 500 个版本，达到上限明确拒绝，保留已有历史。
- 首次内容支持文字灵感、图片、工程文件、视频、音频或 HTTPS 体验链接；名称与四方向仍必填。
- 新增附件每次合计 40 MiB、图片每张 12 MiB/最多八张、JSON 128 KiB。复杂原始工程不会自动在 Worker 转换运行。
- 公开设置和重要标记只更新索引 revision，不另造内容版本；保存新内容使用当前 revision，过期时返回 409。
- 版本可回看，尚无一键将历史恢复为最新稿的接口。作者删除整件作品会删除该作全部版本和附件，区别于正常编辑保留历史。
- HTTPS 使用 `__Host-changxu_workspace`（Secure、HttpOnly、SameSite=Lax、Path=/、无 Domain），回环 HTTP 开发使用单独名称。R2 只存 256 位随机令牌的 SHA-256 和随机 owner，不存明文令牌；完全忽略客户端身份头。
- Cookie 初始有效期 365 天；幂等 POST 在剩余不足 30 天时延长同一 token/owner，GET 永不续期。清除 Cookie、长期到期、换浏览器/设备不能自动恢复旧空间；不删除旧记录，本轮不建立恢复码系统。
- 服务端 session 已存在但坏 JSON/结构时返回 503，保留当前 Cookie，不把暂时故障当成新访客。未知作品 schema 或混合私密索引也返回 503，不自动推断成公开旧记录。接口 JSON 与文件 API 响应禁共享缓存并带 `Vary: Cookie`。

## 验证

2026-10-26 本轮：325 项 API 检查及全量 TypeScript 检查通过；36 项本地真实浏览器/R2 检查通过，依据为 `formspace/scripts/test-api.mjs` 与 `formspace/outputs/qa-changxu-local.json`。已验证文件直接上传、刷新和跨标签页同空间、不同浏览器拒绝读写、公开/私密版本、Cookie 丢失后旧稿保留及精确删除。之前文心账号版的 177/25 项检查和第 2 版发布属于历史验收，不是本轮免账号生产发布证明。
