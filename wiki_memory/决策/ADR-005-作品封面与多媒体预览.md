# ADR-005：作品封面与多媒体预览

用户已采纳影视细化建议并明确授权开始制作。以下记录已确认规则、当前源码实现与实际能力边界；本地完成不等于已线上发布。

## 已确认的产品规则

封面以作品自身内容展示，让访客不必下载专业工程文件即可了解作品。作者上传封面优先；封面保持选填，可从能够处理的内容提取画面，失败时使用明确占位，不阻止保存。

| 方向 | 展示与操作 |
| --- | --- |
| 三维 | 真实模型动效、旋转缩放和细节查看 |
| 影视 | 封面图片与播放键；卡片预览短片段，详情观看公开完整视频 |
| 交互 | 可网页运行的直接体验；其余使用演示视频，并可提供体验原地址 |
| 其他 | 按实际内容提供图片、音频、视频、模型或文字/文件档案 |

预览操作和进入详情分开，触屏有明确按钮；列表一次仅激活一个预览，声音由访客主动开启，离开或切走时暂停。影视选段保持选填，不要求另外上传预告片；结束后提供「查看完整作品」，不强制跳转。

所有访客封面、预览和完整影片均来自作者选定的公开展示版本。新私密上传不替换公开画面；公开作品不自动开放全部历史、过程或源文件。

## 当前源码实现

`formspace/src/MediaPreview.tsx` 在卡片和详情中按内容选择模型、影片、声音、HTTPS 嵌入体验、图片或档案占位。详情可通过 `WorkDetail.tsx` 切换已有媒体。真实 GLB、单文件 OBJ、STL 由 ModelViewer 查看；图片支持切换与放大；音视频使用浏览器控件；交互 iframe 使用沙箱并提供新窗口入口。

影视卡片缺省从零秒播放约 20 秒，短于该长度的影片播至结尾；作者可选填 `previewStart`、`previewEnd`，结束须晚于开始。20 秒是本次制作默认值，不是用户要求的硬性时长。卡片按设定片段结束，详情完整播放同一公开版本的视频。

`WorkForm.tsx` 调用 `media-cover.ts` 尝试从 MP4/WebM 视频帧、GLB/OBJ/STL 模型提取封面；有作者选择图片时优先使用，生成失败或超时仍可保存。模型提取仅支持浏览器可读取的单文件资源，模型大于当前提取上限时跳过，不影响工程归档。

## 权限与媒体安全边界

新作品和每次新保存的内容版本先私密。公开展示版及公开历史节点分开设置，公开展示不自动公开过程、困难、解决或心得。私密版本的文件 URL 也必须鉴权，不能仅隐藏页面按钮。

新上传原件 source 与网页模型 model 使用不同角色和地址；原件下载默认关闭，公开版本需作者明确允许。公开预览必须把对应模型或影音字节交给浏览器，不能承诺预览内容防下载。旧版已公开记录保留原展示和下载兼容；四件系统展品继续使用已验证的公开副本。

GET、HEAD、Range 在读取前执行相同权限检查，文件响应为 `private, no-store`。撤回公开后再次请求需重新鉴权，已被访客合法下载的本地副本无法远程收回。

## 运行边界与验证

Worker 不会自动转换 MAX、BLEND 或影视工程，也不会解压执行上传 ZIP。现有四个 MAX 的 GLB 来自离线转换；新增专业源文件需要另附浏览器可运行的预览或演示。外部 HTTPS 地址可能被目标网站限制嵌入，保留新窗口入口；通用外部网站并不保证在沙箱内完整运行。

本轮已通过 177 项接口检查、25 项真实本地 R2 集成、桌面与影视流程、10 项节点/分享/撤回、64 项移动视口及 28 项扩展媒体检查。模型/视频封面、卡片播放、详情全片、沙箱交互、音频、图片放大与私密资源隔离均已实测；第 2 版发布及线上匿名验收已完成。
