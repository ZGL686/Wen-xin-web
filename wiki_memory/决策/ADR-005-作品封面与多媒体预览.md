# ADR-005：作品封面与多媒体预览

这是产品讨论确认的目标，不是已经实施的媒体功能。继续遵守只讨论、不制作的阶段约束。

## 已确认的产品目标

封面使用作品自身内容处理展示，让访客不下载原文件、不打开专业软件，就能了解作品及细节，并在封面区域获得适合该作品的预览。

| 主方向 | 需求 |
| --- | --- |
| 三维 | 作品自身的三维动效展示和交互查看，延续已有真实三维预览的体验 |
| 影视 | 作者上传的封面图片带播放键，可在封面内播放视频预览 |
| 交互 | 可在网页运行的直接操作，不能网页运行的通过演示视频展示效果；此组合已由用户确认 |

封面仍为选填，不能因为缺少手工封面而阻止作品保存。原始工程、公开封面和预览资源是不同用途的内容，不因公开预览而自动公开私密原件或过程版本。

## 产品建议（尚待确认）

- 把预览/播放/体验与进入作品详情分开，手机有明确操作入口，减少拖动模型与滚动列表的冲突。
- 列表一次只激活一个预览，视频默认不自动出声，离开卡片时暂停；复杂体验可在站内放大或全屏。
- 作者上传封面优先；没有时从可处理的模型或视频提取画面，可后续替换。处理失败或暂无预览时使用清楚占位，不挡住保存。
- 所有公开封面和预览取自作者选定的公开展示版本，新的私密上传不自动替换访客画面。
- 其他方向按实际内容选择图片、视频或音频等预览，具体支持范围另行讨论。

## 待定义的边界

三维预览激活方式与原件转换流程、影视预览是完整视频还是选定片段、音量/进度/全屏、交互运行资源的提供方式、封面自动生成范围，尚未最终确定。封面预览不表示所有 MAX/BLEND/影视工程都能自动转换，不能预先承诺任意上传文件直接运行。

## 已核实的当前实现

本机 `formspace/src/App.tsx` 的 WorkCard 只显示封面 img 和进入详情入口；真实三维预览位于首页展台与详情页。`ModelViewer.tsx` 支持已有 GLB/单文件 OBJ/STL 的旋转缩放等；现有 MAX 的网页资源由离线转换准备。视频播放、交互作品运行和版本绑定尚未实现。
