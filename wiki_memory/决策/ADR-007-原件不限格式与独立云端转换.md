# ADR-007：原件不限格式与独立云端转换

## 已确认要求

用户要求三维原文件不按格式限制上传，选择独立云端转换，即个人电脑关机后仍可处理；目前没有云资源，需要先确定部署方案。访客继续免账号，转换服务配置属于项目管理侧，不新增访客登录。

## 已实施的归档能力

`source` 接受任意后缀和无后缀文件，保留原名和原字节；对象路径使用固定角色及规范后缀，未知后缀存为 `source.bin`，不以输入名拼接路径。全部原件读取均为 `application/octet-stream`、附件下载及 `nosniff`，包括 GET、HEAD、Range 和旧地址。其他媒体的格式、签名和授权检查不变。

每次新增文件合计仍为 40 MiB。用户提出的格式不限制不能解释为文件体积、数量或成本无限。GLB、单文件 OBJ、STL 可提供独立网页模型；未知原件不自动获得 modelUrl。封面、详情和表单根据真实资源说明是否已有预览，不生成虚构队列、百分比或转换成功。

原件和预览模型仍分角色、分权限；补充模型是同作品的新私密版本，原件不改写，公开展示不自动更换。现有四个 MAX 对应模型和封面来自离线真实转换，不能据此推断新 MAX 已有在线转换服务。

## 待验证方案（proposed）

优先验证 Autodesk APS 3ds Max Automation 的真实引擎及用户 MAX2026 文件；尚无账号凭据和引擎枚举结果，不能保证 2026、插件或压缩场景可用。若不兼容，再评估独立 Windows Max2026 转换环境。方案与官方来源见 `docs/cloud-conversion-plan.md`，此 provider 选型尚未确认为正式运行方案。

未来任务绑定作品、版本和源哈希，衍生资源独立保存；异步回写不能改不可变内容快照、公开版指针或覆盖作者另附模型。只有真实提交上游任务才显示排队，输出验收成功才显示成功。未知/不兼容格式继续归档并明确无预览；不承诺所有三维格式、版本和依赖均可自动转换。
