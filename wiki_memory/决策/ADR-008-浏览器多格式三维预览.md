# ADR-008：浏览器多格式三维预览

用户要求在现有 React/Vite 网站直接查看 GLB、glTF、OBJ、STL、FBX、STEP，具有专业查看器常见的平滑旋转、平移、缩放、局部聚焦、居中、复位、全屏和触屏手势，保留当前页面与功能。

沿用项目既有 Three.js 0.183.x 和 PBR/环境光/阴影场景，加入 camera-controls 3.1.2 负责相机惯性与过渡。未嵌入另一套网站或整体替换现有 UI。STEP/STP 使用 occt-import-js 0.0.23，在专用 Worker 中网格化；任务完成、取消或 120 秒超时后终止 Worker。MAX 等原生工程的独立云转换仍遵守 [[决策/ADR-007-原件不限格式与独立云端转换]]，本次浏览器解析不代表该云服务已经部署。

`shared/portfolio.ts` 统一直接模型与预览扩展名。直接原件 GLB/glTF/OBJ/STL/FBX/STEP/STP 可生成独立 model 角色副本；任意原件 ZIP 不自动认作模型。作者明确选择的预览 ZIP 可以包含一份主模型及配套数据、MTL、纹理。文件夹和多文件入口在浏览器保持相对路径生成预览包，不执行其中脚本。模型和原件的公开/私密授权仍分别校验。

所有配套依赖只从提供的模型包或内嵌数据读取，未提供的外部地址拒绝请求。解析器会处理包含中文、空格的路径，不凭同名文件覆盖完整路径。模型包最多 256 项、解压后最多 80 MiB；每次新增上传仍为 40 MiB。模型原件字节和历史不改写，访客无需主动下载文件或安装软件，但浏览器仍须获取预览字节。

Draco、Meshopt、KTX2 按需加载；Draco/Basis/OCCT 解码文件由 `predev` / `prebuild` 从锁定 npm 依赖复制到本站，含上游许可，不依赖外部 CDN。OCCT JavaScript/WASM 保持独立可替换并分发 LGPL 许可。生成目录忽略提交，由源码、锁文件和准备脚本复现。

渲染按相机变化与用户操作触发，静止、离屏和隐藏页面停止重绘；复位和居中直接调整镜头，不重新下载模型。像素比有上限，大于 50 万三角形时降为 1 并关闭动态阴影。没有承诺任意规模装配、全部插件材质、固定 FPS 或原生 CAD 曲面精度；CAD 原件继续独立保存。

实现为 `src/ModelViewer.tsx`、`src/model-loader.ts`、`public/decoders/step-worker.js`、`src/media-cover.ts`、`src/WorkForm.tsx` 与 `worker/api.ts`。维护与使用见 [[知识/模块/浏览器三维查看器]]。

选型来源：[camera-controls](https://github.com/yomotsu/camera-controls)、[Three.js GLTFLoader](https://threejs.org/docs/pages/GLTFLoader)、[occt-import-js](https://github.com/kovacsv/occt-import-js)。Online3DViewer 同样支持多格式，但整套引入会重复本项目已有渲染与界面；本次选择复用已有底层组件。
