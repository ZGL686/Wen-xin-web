# ADR-003：文心定位与两级作品分类

此前授权制作的规则已进入 React + Vite 源码并发布；本轮用户重新要求仅讨论名称，命名部分重新开放，分类及个人作品集规则继续有效。网站暂不改动，新名称确认与恢复制作需以用户后续指令为准。

## 已确认的产品原则

- 当前已上线名称为文心，副标题为树莓成熟时，原取意“为文之用心”。用户现反馈名称已被使用并重新讨论命名，偏好 2—3 字中文品牌名，新名待确认；本阶段不执行品牌替换。首阶段主要服务高校数媒学生，面向数字媒体技术创作者。
- 每位创作者有独立作品集和分享链接，兼顾公开展示与私密归档。
- 作品库第一排固定为全部、交互、影视、三维、其他。「全部」是浏览筛选，不是上传方向。
- 每件作品只选一个主方向，可以填写多个标签；首次主方向必填，标签选填。
- 第二排是所选方向下作者自填标签，从该方向已有作品汇总去重，不采用产品、家具等固定二级枚举。
- 切换主方向清除此前标签筛选；全部状态隐藏第二排，具体方向才显示。
- 现有四件真实作品保留；没有作品的方向使用空状态，不制造演示作品。

## 当前实现与制作选择

`formspace/src/PortfolioViews.tsx` 的 Collection 统一提供公开作品库和个人空间的分类、搜索、收藏及排序。具体方向下的标签取当前允许展示的作品集合汇总，其他作者的私密作品不进入访客标签和数量。

本次制作采用二级标签单选，并提供「不限标签」重置；这是实现选择，不声称用户此前指定过单选。每件作品自身仍可有多个标签。方向下暂无标签时给出补充提示，空方向维持可理解的空状态。

`formspace/shared/portfolio.ts` 与服务端按交互、影视、三维、其他校验。初始四作和旧版产品设计、家具设计、空间建筑记录兼容映射为三维，并把原分类加入标签，不丢失旧语义。

个人空间使用稳定 slug。公开分享页只返回该空间选定的公开展示版本；「我的空间」展示登录作者最新稿，包含私密作品。初始四件属于系统展品，不能由首先登录的用户冒认作者或修改。完整版本与公开过程边界见 [[决策/ADR-004-创作过程与私密版本历史]]。

## 风格与验证边界

本次保留原有奶油白、墨黑、荧光绿和编辑式排版，继续使用 React + Vite + TypeScript。品牌、个人空间、上传编辑、详情和分类已由 App、PortfolioViews、WorkForm、WorkDetail 等源码承载。

分类、个人空间与媒体流程已完成浏览器验收，390/320 手机视口检查通过，并已完成第 2 版发布及线上匿名验收。具体范围见本轮交付日志。
