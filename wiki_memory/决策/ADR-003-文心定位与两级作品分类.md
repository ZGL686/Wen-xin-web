# ADR-003：文心定位与两级作品分类

这是已确认的产品目标，不是已上线功能说明。本阶段仅产品讨论，页面、品牌资源、上传 API 和数据尚未按本决策实施。

## 已确认

- 平台正式名称：文心；网站副标题：树莓成熟时；品牌含义为“为文之用心”。
- 第一阶段主要服务高校数媒学生，未来面向数字媒体技术创作者。
- 每位创作者拥有独立作品集与分享链接，兼顾公开展示和私密归档。
- 作品库第一行固定按顺序呈现：全部、交互、影视、三维、其他。「全部」为筛选入口，不是上传时的作品类型。
- 第二行属于所选方向下的作者自填作品标签，例如三维下面的产品设计、家具设计；它们不与四个方向并列。
- 每件作品选择一个主方向，可以填写多个标签。
- 第二行从当前方向已有作品中汇总标签，相同标签合并，不重复生成按钮。
- 切换主方向时清除之前的标签筛选，新方向从完整列表开始。
- 全部状态隐藏第二排标签，选定具体方向后才显示。

## 建议与待确认

二级标签筛选采用单选还是多选、方向下没有标签时如何呈现，留待后续讨论。作品可以有多个标签，不代表筛选必须多选；这两个概念应分开确认。

标签应基于真实保存的作品内容汇总，不能写死为产品/家具等固定二级枚举。原有分类需要将来兼容，不能因更名丢失历史语义。现有四件作品保留真实内容；其他方向目前没有作品时不制造演示条目。

## 实现边界

未来获准实施时，需要连同上传表单、服务端校验、历史记录读取适配和筛选行为一起处理。现有 API 只接受旧分类，单独替换按钮会造成分类保存错误。本轮不做这些改动。
