# ADR-006：免账号浏览器创作空间

用户明确要求移除账号登录，并确认“打开即用，由当前浏览器自动识别，保留私密历史和作者权限”。这是当前有效的身份方式；文心时期的 Sites 账号要求不再适用于应用。

首次同源 POST /api/session 生成 256 位随机秘密，服务器只在 R2 sessions/ 保存 SHA-256、随机 workspace owner ID、有效期；HTTPS 通过 Secure/HttpOnly/SameSite=Lax/Path=/、无 Domain 的 __Host-changxu_workspace Cookie 返回，JSON 不返回秘密。仅本机 HTTP 使用开发名，对外必须 HTTPS。

有效空间复用同一秘密与 owner。期限 365 天，POST 在不足 30 天时滚动延长；前端初始化始终经过幂等 POST，再用只读 GET /api/me 确认 Cookie 和 owner。单标签 Promise 与跨标签 Web Locks 协调首开；普通请求或 XHR 的 401 最多准备一次，身份变化时不重试旧写入。

文件和版本仍存服务端，Cookie 仅是访问凭据。不同浏览器不共享空间，不信任 oai 身份头或公开链接。清除 Cookie、换浏览器/设备或凭据到期后无法自动恢复旧空间，本轮不提供恢复码、账号或跨设备同步。身份变化时保留正在编辑的文字与本次所选文件，禁止旧作品自动转存新空间。

旧 account owner 的私密和公开记录原样保留，不迁移或认领；已有公开展示和明确 v1 公开记录继续兼容。新作/新版本默认私密，展示版与公开过程节点分离；GET/HEAD/Range 读取都依照作者或公开节点授权。

存在但损坏的 session row 返回 503，不覆盖浏览器秘密；未知 schema 或损坏作品索引返回 503，不降级为旧公开记录。所有变更校验同源，用户和文件响应 private,no-store 且 Vary:Cookie。保持 CAS 并发保护、失败回滚和原件/预览分角色。

325 项接口、本地 36 项真实浏览器 R2、手机视口 75 项与线上 32 项检查通过。独立审计发现的坏会话覆盖、未知 schema 泄露与编辑稿隐藏边界已修复并回归验证。线上临时作品始终私密并删除，报告不含 Cookie 值或私密内容。

源码与接口以 formspace/shared/portfolio.ts、worker/api.ts、src/ui-utils.ts、App.tsx 为准。关联 [[当前状态/系统架构]]、[[决策/ADR-004-创作过程与私密版本历史]]、[[知识/运维/部署与交付]]。
