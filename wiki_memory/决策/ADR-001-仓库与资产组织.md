# ADR-001：仓库与资产组织

用户要求整理整个 3d 工作区并推送到 Wen-xin-web。根目录作为统一 Git 仓库，保留 `formspace/` 为应用目录；其原有 Git 元数据迁到根，继承原提交历史。操作前完整备份保存在本机忽略目录 `.local-history/`。

根部 MAX 归入 `assets/source/`；转换资料归入 `assets/pipeline/`；网页下载与预览副本继续留在 `formspace/public/`，不改为应用外符号链接。原文件按哈希验证，重复副本有各自用途。

历史 WorkBuddy ZIP 与校验和归入 `deliverables/`，不覆盖历史包；展开目录、依赖和缓存仅本地保留。接手文档和截图单独放在 `docs/` 便于浏览。历史柜子过程归入 `archive/cabinet-20261011/`，不将旧脚本误认为可直接安全重跑。

MAX/BLEND/FBX/GLB/ZIP 通过 Git LFS 管理。仓库克隆后执行 `git lfs pull` 和 `node tools/verify-project.mjs`，确认不是指针文件并校验真实资产。

GitHub 主仓库是 monorepo；未来更新原 Sites 站点需使用独立应用 checkout，不能直接把根目录交给单应用源码 helper。
