# ADR-001：仓库与资产组织

用户要求整理整个 3d 工作区并推送到 Wen-xin-web。根目录作为统一 Git 仓库，保留 `formspace/` 为应用目录；其原有 Git 元数据迁到根，继承原提交历史。操作前完整备份保存在本机忽略目录 `.local-history/`。

原始 MAX 现位于 `assets/3d source/`（用户由初始 `assets/source/` 改名，四件网页基线原件已重新核对哈希）；转换资料归入 `assets/pipeline/`；网页下载与预览副本继续留在 `formspace/public/`，不改为应用外符号链接。原文件按哈希验证，重复副本有各自用途。

2026-11-05 用户确认整理整个项目并直接使用原格式文件。MAX 和配套贴图集中于 `assets/3d source/`，导出模型归 `assets/pipeline/`，原生渲染归 `assets/renders/`，说明与本地模型验收归 `docs/models/`。按 `AGENTS.md` 仅在用户另行要求时制作交付压缩包。

历史 WorkBuddy 的 47 个文件按旧 ZIP 的逐项内容保存在本机忽略目录 `.local-history/workbuddy-20261025/`。旧包和重复副本移入本机整理备份，Git 历史保留原包。接手文档在 `docs/workbuddy/`，历史柜子过程在 `archive/cabinet-20261011/`。

MAX/BLEND/FBX/GLB/ZIP 通过 Git LFS 管理。仓库克隆后执行 `git lfs pull` 和 `node tools/verify-project.mjs`，确认不是指针文件并校验真实资产。

GitHub 主仓库是 monorepo；未来更新原 Sites 站点需使用独立应用 checkout，不能直接把根目录交给单应用源码 helper。
