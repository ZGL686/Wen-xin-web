# Browser model decoders

Generated by `npm run predev` / `npm run prebuild` from the locked npm dependencies. The files are hosted on the same Site; viewers do not depend on a third-party CDN.

- Three.js 0.183.x (MIT): https://github.com/mrdoob/three.js . Its Draco decoder and Basis transcoder are distributed with the upstream library; upstream license notes accompany the generated files.
- camera-controls 3.1.2 (MIT): https://github.com/yomotsu/camera-controls . Bundled as an application module.
- occt-import-js 0.0.23 (LGPL-2.1), including Open Cascade: https://github.com/kovacsv/occt-import-js . Unmodified JavaScript/WASM is separately loaded and replaceable. The generated `occt/` directory includes both upstream license files. Source and build instructions for this exact version are included in the npm distribution and available in the upstream repository.

STEP tessellation runs in `step-worker.js`, which is terminated on completion, cancellation or timeout. STEP preview geometry does not replace the archived CAD source or preserve its parametric editing history.
